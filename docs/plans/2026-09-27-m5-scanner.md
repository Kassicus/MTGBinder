# Binder M5 (Scanner) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scan cards into the collection with the iPhone camera. The Mac's own text recognition identifies most
cards and their printing; Claude identifies what it can't (with an API key). A queue shows every capture for a
quick check before the cards are added.

**Architecture:**
- **OCR helper (`native/ocr.swift` → `bin/ocr`).** A persistent Swift process running Apple Vision text recognition.
  The server talks to it through `src/server/scanner/ocr-client.ts` and builds it when it's missing or stale.
- **Matcher (`src/server/scanner/matcher.ts`).** Pure functions, unit-tested:
  - reads the title, set code, collector number, copyright year, and foil star;
  - decides confident, printing-uncertain, or unsure against the card data.
- **Scan queue (`src/server/scanner/`).** `scan_items` rows and images under `data/scans`, a worker (OCR two at a
  time, Claude two at a time), and routes under `/api/scan`.
- **Claude reader (`src/server/scanner/claude.ts`).** The fallback, using the API key saved from Settings in `.env`.
- **Web.** A Scan page (camera, guide, manual and auto capture, the queue) and Settings sections for the scanner and
  the API key.
- **Also from M3's and M4's follow-ups:** English default printings; TCGplayer CSV names.

**Tech Stack:** Same as M1–M4: Node 24 running TypeScript directly, Hono 4, better-sqlite3 13, zod 4, React 19, React
Router 8, TanStack Query 5, Tailwind 4, Vite 8, Vitest 5. New: Swift 6 with Apple Vision (Xcode's command line
tools, already on this Mac), and `@anthropic-ai/sdk` 0.128.0 (spec §3.3).

**Spec:** `docs/specs/2026-09-26-binder-design.md`. This plan covers milestone 5 of §8:
- §5.1 (Scanner: capture, pipeline, queue, OCR helper, Continuity Camera notes, benchmark);
- §5.6's Scanner and API key settings;
- §6's OCR and Anthropic error handling;
- the M5 items in `docs/plans/m3-followups.md` and `docs/plans/m4-followups.md`.

**How this plan was made:** Every code block was prototyped in a scratch copy of the project. Replaying this plan
task by task onto the current project reproduces that prototype exactly, and every checkpoint passes
(588 tests at the end, typecheck clean, build clean). The prototype ran on a copy of the real card data:

**Decisions made while prototyping (flagged for review):**
1. **Positions are read over the card's text, not the photo.** The spec's "top 12%" and "bottom 20%" are measured
   from the top of the highest line of text to the bottom of the lowest, and a capture keeps an 8% margin around
   the guide. A card that isn't placed exactly still reads right. Card-edge detection with Vision was tried and
   dropped: it sometimes took the art box for the card and cropped off the collector line.
2. **More ways to be sure of the printing.** Besides the set code, the collector number (2003–2014 cards print one
   without a set code) and the copyright year ("© 1993-2009") narrow the printings; one left is the printing. Only
   English printings count, since OCR reads English titles, so a card with one English printing needs nothing else.
   Old cards whose printing can't be told apart still go to "Check the printing".
3. **An exact name wins.** A title that is exactly a card's name is sure even when a longer name is close ("Flight"
   and "Flighty"). Fuzzy names keep the spec's 0.92 and 0.05 gap.
4. **Set codes one character off** (TDM read as TOM) are tried when the one read names no printing. The name check
   (0.80) keeps that safe.
5. **Candidate names come from M4's exhaustive name search**, now shared (`cards/fuzzy.ts`), rather than an FTS
   trigram query. It is as fast, about 1 ms, and a typo in a name's first letter still finds the card.
6. **Default printings prefer English** everywhere (an M4 follow-up), and scans use the same default-printing rule
   as the rest of Binder (an M3 follow-up). The name index rebuilds once at the next start.
7. **Claude's answer must say it's at least 0.5 sure**, besides matching the card data. The model is
   `claude-opus-5`, as the spec says; Opus 5.5 is newer, if you'd rather use it.
8. **Empty auto captures are dropped.** Auto mode also captures the bare mat after a card is lifted. The server
   drops an auto capture in which OCR finds no text at all. Manual captures are never dropped (spec: "The capture is
   never dropped").
9. **The queue polls the whole list every second** (`GET /api/scan/items`), not `?since=`. The queue stays small,
   and the page stays simple.
10. **The OCR helper is built by `pnpm setup`, and by the server before its first scan** when it's missing or older
    than its source. One helper process takes two requests at a time, in turn.
11. **The API key lives only in `.env`** (mode 600). A shell's `ANTHROPIC_API_KEY` isn't used, so Remove really
    turns Claude off. The server never sends the key back.
12. **TCGplayer CSV rows:** Simple Name first; otherwise a trailing "(…)" or "[…]" variant is dropped when the full
    name doesn't match.
13. **`scan_items` gains `reason` and `auto`** (migration 003). Review scans can be identified again, for example
    after adding a key.

## Global Constraints

Everything from M1–M4 still applies:
- The server listens on `127.0.0.1:4321`, and `/api/*` sits behind the local-only guard.
- Node `>=24`.
- Every relative import has an explicit `.ts`/`.tsx` extension.
- Erasable TypeScript only.
- Exact pinned dependency versions. **M5 adds exactly one: `@anthropic-ai/sdk` 0.128.0.**
- API errors are JSON `{ "error": { "code", "message" } }`.
- Every change goes through a POST, PUT, PATCH, or DELETE whose body is validated by zod. A body that isn't JSON is
  a 400 `bad_request`; a capture is a JPEG body of at most 15 MB.
- Every user-supplied value in SQL is a bound parameter.
- Dark `stone` palette with an `amber` accent, Tailwind utilities only.
- **Not a git repository**: every task ends with a checkpoint (`pnpm typecheck && pnpm test`, plus `pnpm build` for
  web tasks), never a commit.
- **Never write to `data/`.** End-to-end checks use a copy in `/tmp`.

New in M5:
- **Nothing a person captures is lost silently.** Every failure (OCR, the helper, Claude, no key) leaves the scan
  in review with its error. The only capture dropped is an auto-mode capture with no text at all.
- **Never confidently wrong.** A scan is confident only by the rules of spec §5.1.2 as amended in the Decisions
  above. On the benchmark, none of the 140 readings was confidently wrong.
- **The API key never leaves the server** and is stored with mode 600. Nothing logs it.
- **Spec §2's model:** `claude-opus-5` at effort `low`, with structured output and server-side refusal fallbacks.

## Review Focus

1. **Real captures.** A card off-center, tilted, glaring, or in a sleeve must still read, or fall back to review;
   never to a wrong card or printing. *Tests: Task 3 "finds the title and collector line of a card that sits lower
   and smaller in the photo", "tries set codes one character off…", "is unsure of the printing…"; Task 8's
   benchmark.*
2. **Old frames with no set code or number.** They must come back as the right card with "Check the printing" and
   the likeliest printing, or confident only when the number or year leaves one printing. *Tests: Task 3 "narrows
   printings…", "is unsure of the printing…".*
3. **A helper that fails.** Swift tools missing, the helper crashing or hanging mid-queue: each affected scan goes
   to review with the error, and the queue keeps going. *Tests: Task 2 crash, timeout, and failed-preparation cases;
   Task 5 "puts an unknown card in review… and a failed OCR with its error".*
4. **Auto mode in a real session.** A card left in place is captured once. Lifting it leaves no clutter. A nudge
   restarts the wait. Edits to a scan still being read are refused, not lost. *Tests: Task 7 `createAutoCapture`;
   Task 5 "drops an auto capture with no text…", "refuses edits it cannot make" (409 `busy`).*
5. **The API key and Claude.** The key is never echoed back, the file mode is 600, a bad key is explained, and

### Task 1: Card data groundwork: English default printings, a shared name search, TCGplayer names

Three changes the scanner builds on, all from earlier milestones' follow-ups:

- **English default printings** (M4 follow-ups). The default printing ignored language, so a card whose newest
  regular printing is Italian-only (Abu Ja'far's Rinascimento printing) showed that printing everywhere. Scans read
  English titles, so their default printing must be English too.
- **A shared name search.** M4's exhaustive, lossless fuzzy search moves from decklist import to
  `src/server/cards/fuzzy.ts` and returns every card identity above a threshold rather than only the best. The
  scanner needs the runner-up to judge how clearly the best name wins. Decklist import's results don't change.
- **TCGplayer names** (the owner confirmed it). TCGplayer's CSV writes the variant into the Name column ("Lightning
  Bolt (Borderless)"), so those rows came back unresolved. Import now prefers TCGplayer's Simple Name column, and
  otherwise drops a trailing "(…)" or "[…]" when the name as written doesn't match.

**Files:**
- Create: `src/server/cards/fuzzy.ts`
- Modify: `src/server/cards/repo.ts` (`DEFAULT_PRINTING_ORDER`, `CARD_NAMES_VERSION`), `src/server/decks/import.ts`
  (uses the shared search), `src/server/collection/import.ts` (TCGplayer names)
- Test: `tests/server/cards-repo.test.ts`, `tests/server/collection-import.test.ts`

**Interfaces:**
- Consumes: M4's lossless fuzzy search in `src/server/decks/import.ts`, `CardNameIndex` from `cards/names.ts`.
- Produces:
  - `createFuzzySearch(keys): FuzzySearch` in `src/server/cards/fuzzy.ts`, where

```ts
import { jaroWinkler } from '../../shared/similarity.ts'
import type { CardNameIndex } from './names.ts'

export interface FuzzyHit {
  oracleId: string
  score: number
}

/** Card identities scoring at least `threshold` against a normalized name, best first. */
export type FuzzySearch = (query: string, threshold: number) => FuzzyHit[]

/** Symbols a normalized name uses: a–z, 0–9, and the space. */
const SYMBOLS = 37

/** A character's symbol slot. Anything but a–z and 0–9 shares the space's slot, which can only raise a shared count. */
function slot(code: number): number {
  if (code >= 97 && code <= 122) return code - 97 // a–z → 0–25
  if (code >= 48 && code <= 57) return code - 22 // 0–9 → 26–35
  return 36
}

/**
 * Searches every name for those scoring at least a threshold, for decklist import (spec §5.4.2) and scan matching
 * (§5.1.2). A cheap upper bound on each name's score skips most names unscored, and it never skips one that could
 * reach the threshold:
 * - With l the common prefix (at most 4), Jaro–Winkler is jaro + 0.1·l·(1 − jaro), which rises with jaro, so it
 *   reaches the threshold only when jaro ≥ need = (threshold − 0.1·l) / (1 − 0.1·l).
 * - jaro = (m/|q| + m/|k| + (m − t/2)/m) / 3 ≤ (m/|q| + m/|k| + 1) / 3, as transpositions t ≥ 0; and the matches m
 *   can't exceed the shorter length, nor the symbols the two names share (Σ of the smaller count of each symbol).
 * So a name is skipped when m < (3·need − 1) / (1/|q| + 1/|k|) for m = the shorter length, or for m = the shared
 * symbols. The shared count is |q| less the query's symbols the name lacks, summed rarest symbol first and cut short
 * once too many are missing.
 *
 * Counts every name's symbols once and returns the search for one normalized name: each card identity scoring at
 * least `threshold` (by its best name), best first; equal scores keep the order of the names in the index.
 */
export function createFuzzySearch(keys: CardNameIndex['keys']): FuzzySearch {
  const counts = new Uint16Array(keys.length * SYMBOLS)
  const frequency = new Float64Array(SYMBOLS)
  keys.forEach(({ key }, i) => {
    for (let c = 0; c < key.length; c++) {
      const s = slot(key.charCodeAt(c))
      counts[i * SYMBOLS + s]!++
      frequency[s]!++
    }
  })
  return (query, threshold) => {
    // The jaro each prefix length 0–4 needs, less a hair so float rounding can't skip a name scoring exactly the
    // threshold.
    const needs = [0, 1, 2, 3, 4].map((l) => (threshold - 0.1 * l) / (1 - 0.1 * l) - 1e-9)
    const queryCounts = new Uint16Array(SYMBOLS)
    for (let c = 0; c < query.length; c++) queryCounts[slot(query.charCodeAt(c))]!++
    const used: number[] = []
    for (let s = 0; s < SYMBOLS; s++) if (queryCounts[s]! > 0) used.push(s)
    used.sort((a, b) => frequency[a]! - frequency[b]!)
    const best = new Map<string, { score: number; at: number }>()
    for (let i = 0; i < keys.length; i++) {
      const { key, oracleId } = keys[i]!
      const prefixMax = Math.min(4, query.length, key.length)
      let l = 0
      while (l < prefixMax && query.charCodeAt(l) === key.charCodeAt(l)) l++
      const minShared = (3 * needs[l]! - 1) / (1 / query.length + 1 / key.length)
      if (Math.min(query.length, key.length) < minShared) continue
      const allowedMissing = query.length - minShared
      let missing = 0
      for (const s of used) {
        const lacking = queryCounts[s]! - counts[i * SYMBOLS + s]!
        if (lacking > 0 && (missing += lacking) > allowedMissing) break
      }
      if (missing > allowedMissing) continue
      const score = jaroWinkler(query, key)
      const known = best.get(oracleId)
      if (score >= threshold && (known === undefined || score > known.score)) best.set(oracleId, { score, at: i })
    }
    return [...best]
      .sort(([, a], [, b]) => b.score - a.score || a.at - b.at)
      .map(([oracleId, { score }]) => ({ oracleId, score }))
  }
}
```

```ts
        const lacking = queryCounts[s]! - counts[i * SYMBOLS + s]!
        if (lacking > 0 && (missing += lacking) > allowedMissing) break
      }
      if (missing > allowedMissing) continue

      if (score >= FUZZY_THRESHOLD && (best === null || score > best.score)) best = { oracleId, score }
    }
    return best
  }
```

### Task 2: The OCR helper and its client

Spec §5.1.4: a persistent Swift process runs Apple Vision's text recognition (`.accurate`, no language correction,
`en-US`). Prototyping found one setting the spec doesn't name: Vision skips text smaller than 1/32 of the image by
default, and a card's collector line is about 1.5% of its height, so the helper sets `minimumTextHeight = 0`.
On Scryfall's large images (672 × 936) a card reads in 80–150 ms.

The client keeps one helper running. It matches answers to requests by id. A crash fails only the requests waiting
on that process. A request that takes longer than 10 s fails, and its process is stopped, so the next request starts
a new one right away. The helper is built by `pnpm setup` and, when it's missing or older than its source, before
the server's first scan (Task 5), so a Binder update never runs a stale helper.

```swift
// Binder's OCR helper (spec §5.1.4): reads one JSON request per line on stdin, {"id": "...", "path": "..."}, runs
// Apple Vision text recognition on that image, and writes one JSON response per line on stdout:
// {"id": "...", "width": 672, "height": 936, "lines": [{"text": "...", "confidence": 0.98,
//   "box": {"x": 0.06, "y": 0.04, "w": 0.5, "h": 0.04}}]}
// Boxes are normalized to the image with the origin at the top left. Failures answer {"id": "...", "error": "..."}.
// Built by `pnpm setup` (swiftc -O native/ocr.swift -o bin/ocr); the server starts it once and keeps it running.
import Foundation
import ImageIO
import Vision

struct Request: Decodable {
  let id: String
  let path: String
}

struct Box: Encodable {
  let x: Double
  let y: Double
  let w: Double
  let h: Double
}

struct Line: Encodable {
  let text: String
  let confidence: Double
  let box: Box
}

struct Result: Encodable {
  let id: String
  let width: Int
  let height: Int
  let lines: [Line]
}

struct Failure: Encodable {
  let id: String
  let error: String
}

let encoder = JSONEncoder()

func send<T: Encodable>(_ value: T) {
  guard let data = try? encoder.encode(value), let text = String(data: data, encoding: .utf8) else { return }
  FileHandle.standardOutput.write((text + "\n").data(using: .utf8)!)
}

func recognize(_ request: Request) -> Result? {
  let url = URL(fileURLWithPath: request.path)
  guard let source = CGImageSourceCreateWithURL(url as CFURL, nil),
    let image = CGImageSourceCreateImageAtIndex(source, 0, nil)
  else {
    send(Failure(id: request.id, error: "Can't read an image at \(request.path)"))
    return nil
  }
  let vision = VNRecognizeTextRequest()
  vision.recognitionLevel = .accurate
  vision.usesLanguageCorrection = false
  vision.recognitionLanguages = ["en-US"]
  // Collector lines are about 1.5% of a card's height, under Vision's default minimum text height.
  vision.minimumTextHeight = 0
  do {
    try VNImageRequestHandler(cgImage: image, options: [:]).perform([vision])
  } catch {
    send(Failure(id: request.id, error: "Text recognition failed: \(error.localizedDescription)"))
    return nil
  }
  let lines: [Line] = (vision.results ?? []).compactMap { observation in
    guard let best = observation.topCandidates(1).first else { return nil }
    let b = observation.boundingBox  // normalized, origin at the bottom left
    return Line(
      text: best.string,
      confidence: Double(best.confidence),
      box: Box(x: b.minX, y: 1 - b.maxY, w: b.width, h: b.height))
  }
  return Result(id: request.id, width: image.width, height: image.height, lines: lines)
}

while let input = readLine() {
  guard let data = input.data(using: .utf8), let request = try? JSONDecoder().decode(Request.self, from: data) else {
    send(Failure(id: "", error: "Not a request: \(input.prefix(200))"))
    continue
  }
  if let result = recognize(request) { send(result) }
}
```

```ts
import { execFile, spawn, type ChildProcessWithoutNullStreams } from 'node:child_process'
import fs from 'node:fs'
import path from 'node:path'
import { createInterface } from 'node:readline'
import { promisify } from 'node:util'

/** One line of text Vision read, with its box normalized to the image (origin at the top left). */
export interface OcrLine {
  text: string
  confidence: number
  box: { x: number; y: number; w: number; h: number }
}

export interface OcrResult {
  width: number
  height: number
  lines: OcrLine[]
}

export interface OcrClient {
  /** Reads the text in an image file. Rejects if the helper fails, crashes, or takes longer than the timeout. */
  recognize(imagePath: string): Promise<OcrResult>
  /** Stops the helper. A later recognize() starts it again. */
  close(): void
}

export interface OcrClientOptions {
  /** The helper's command and arguments. */
  command: readonly string[]
  /** How long one image may take (spec §5.1.4: 10 s). */
  timeoutMs?: number
  /** Runs before the helper first starts, for example to build it; a rejection fails that request. */
  prepare?: () => Promise<void>
}

interface Pending {
  resolve: (result: OcrResult) => void
  reject: (err: Error) => void
  timer: NodeJS.Timeout
  /** The helper process the request went to. */
  proc: ChildProcessWithoutNullStreams
}

/**
 * Talks to the OCR helper (spec §5.1.4): one long-running process that answers one JSON line per request. Answers
 * are matched to requests by id. A crash fails the requests waiting on that process; a timeout fails its request
 * and stops the process. Either way the next request starts a new one.
 */
export function createOcrClient({ command, timeoutMs = 10_000, prepare }: OcrClientOptions): OcrClient {
  let child: ChildProcessWithoutNullStreams | null = null
  let prepared: Promise<void> | null = null
  let nextId = 1
  const pending = new Map<string, Pending>()

  function failAll(proc: ChildProcessWithoutNullStreams, err: Error) {
    for (const [id, p] of pending) {
      if (p.proc !== proc) continue
      clearTimeout(p.timer)
      pending.delete(id)
      p.reject(err)
    }
  }

  function start(): ChildProcessWithoutNullStreams {
    const [bin, ...args] = command
    const proc = spawn(bin!, args, { stdio: ['pipe', 'pipe', 'pipe'] })
    let stderr = '' // this process's last words, for the error when it stops
    proc.stderr.on('data', (chunk: Buffer) => {
      stderr = (stderr + chunk.toString()).slice(-2000)
    })
    createInterface({ input: proc.stdout }).on('line', (line) => {
      let message: { id?: string; error?: string } & Partial<OcrResult>
      try {
        message = JSON.parse(line) as typeof message
      } catch {
        return
      }
      const p = message.id === undefined ? undefined : pending.get(message.id)
      if (!p) return
      clearTimeout(p.timer)
      pending.delete(message.id!)
      if (message.error !== undefined) p.reject(new Error(message.error))
      else p.resolve({ width: message.width ?? 0, height: message.height ?? 0, lines: message.lines ?? [] })
    })
    const stopped = (reason: string) => {
      if (child === proc) child = null
      failAll(proc, new Error(`The OCR helper stopped (${reason})${stderr.trim() ? `: ${stderr.trim()}` : ''}`))
    }
    proc.on('error', (err) => stopped(err.message))
    proc.on('exit', (code, signal) => stopped(signal ?? `exit code ${code}`))
    proc.stdin.on('error', () => {}) // a write to a helper that just died; 'exit' reports it
    return proc
  }

  return {
    async recognize(imagePath) {
      if (prepare) {
        prepared ??= prepare().catch((err: unknown) => {
          prepared = null
          throw err
        })
        await prepared
      }
      child ??= start()
      const proc = child
      const id = String(nextId++)
      return new Promise<OcrResult>((resolve, reject) => {
        const timer = setTimeout(() => {
          pending.delete(id)
          reject(new Error(`OCR took longer than ${timeoutMs / 1000} s`))
          if (child === proc) child = null // the next request starts a new helper right away
          proc.kill('SIGKILL')
        }, timeoutMs)
        pending.set(id, { resolve, reject, timer, proc })
        proc.stdin.write(`${JSON.stringify({ id, path: imagePath })}\n`)
      })
    },
    close() {
      child?.kill()
      child = null
    },
  }
}

const execFileAsync = promisify(execFile)

/**
 * Compiles the Swift helper with `swiftc` when the binary is missing or older than its source. Returns true when it
 * compiled.
 */
export async function buildOcrHelper(source: string, binary: string): Promise<boolean> {
  const built = fs.statSync(binary, { throwIfNoEntry: false })
  if (built && built.mtimeMs >= fs.statSync(source).mtimeMs) return false
  fs.mkdirSync(path.dirname(binary), { recursive: true })
  try {
    await execFileAsync('swiftc', ['-O', source, '-o', binary])
  } catch (err) {
    const detail = (err as { stderr?: string }).stderr?.trim() || (err as Error).message
    throw new Error(
      `Couldn't build the OCR helper with swiftc (install Xcode's command line tools: xcode-select --install): ${detail}`,
    )
  }
  return true
}
```

### Task 3: The matcher and the OCR benchmark

The matcher is spec §5.1.2's decision, as pure functions over what OCR read. Prototyping it against 70 Scryfall
images (1993 frames through 2025, showcase and borderless frames, split, DFC, adventure, MDFC) and against the same
images made to look like phone photos changed a few details. It is still never confidently wrong on either set:

- **Where the title and collector line are** is measured over the card's text, from the top of the highest line
  to the bottom of the lowest, not over the photo. A card that doesn't fill the capture still reads right. The
  collector line has three shapes:
  - "145/269 R" over "M15 • EN" (2015–2019);
  - "U 0201" over "WOE • EN" (2020 on);
  - "…Wizards of the Coast 66/350" (2003–2014; no set code).
- **Which printing.** Besides the set code, the collector number and the copyright year ("© 1993-2009") narrow the
  printings; one left is the printing. Only English printings count, since OCR reads English titles, so a card with
  one English printing needs nothing else. The year window is the printed year and the next (sets out in January
  carry the year before).
- **Which card.** A title that is exactly a card's name wins even when a longer name is close ("Flight" and
  "Flighty"). Otherwise a name needs 0.92 and a 0.05 lead over the next card. Names come from Task 1's exhaustive
  search, not an FTS query, so a typo in the first letter still finds the card.
- **Misread set codes.** When the set code and number name no printing, set codes one character away are tried
  (TDM read as "TOM"). The name check (0.80 against anything on the card) keeps that safe. Split cards print their
  names sideways, outside the title bar, so the name check reads every line.

Create `src/server/scanner/matcher.ts`:

```ts
import { normalizeName } from '../../shared/normalize.ts'
import { jaroWinkler } from '../../shared/similarity.ts'
import type { OcrLine, OcrResult } from './ocr-client.ts'

/**
 * Where the title bar sits: lines whose middle is in the top 12% of the card (spec §5.1.2). Heights are measured
 * over the card's text, from the top of the highest line to the bottom of the lowest, so a card that doesn't fill
 * the photo exactly still reads right.
 */
export const TITLE_BAND = 0.12
/** Where the collector line sits: lines whose middle is in the bottom 20% of the card's text. */
export const COLLECTOR_BAND = 0.8
/** Lines starting right of this are the power/toughness box, never the collector number. */
const PT_BOX_X = 0.7
/** A set-and-number hit is confident when its name is at least this similar to text read on the card. */
export const SET_NUMBER_NAME_SIMILARITY = 0.8
/** A name alone is confident at this similarity… */
export const NAME_SIMILARITY = 0.92
/** …when the next different card scores at least this much lower. */
export const NAME_GAP = 0.05
/** Names scoring below this aren't candidates at all. */
export const CANDIDATE_SIMILARITY = 0.75
/** How many candidates a scan keeps for the review list. */
export const MAX_CANDIDATES = 5

/** What the printed card says, as far as OCR could read it. */
export interface CardReading {
  /** The longest text in the title bar, or null. */
  title: string | null
  /** The set code from the collector line ("M15 • EN" gives "m15"), or null. */
  setCode: string | null
  /** The collector number without leading zeros ("0223" gives "223", "114a/264" gives "114a"), or null. */
  collectorNumber: string | null
  /** The last year in the copyright line ("© 1993-2009" gives 2009), or null. */
  year: number | null
  /** A ★ in place of the • on the collector line, which marks a foil printing. */
  foil: boolean
  /** Every line's text. A set-and-number hit checks its name against all of it (split cards print names sideways). */
  texts: string[]
}

const middle = (box: { y: number; h: number }) => box.y + box.h / 2
const letters = (text: string) => (text.match(/\p{L}/gu) ?? []).length

/** "M15 • EN", "TDM ★ EN": a set code, a bullet (a star on foils), and a language code. */
const SET_LINE = /(?:^|[^A-Z0-9])([A-Z0-9]{3,5})\s*([•★*·])\s*([A-Z]{2,3})\b/
/** A line holding only a collector number: "145/269 R", "M 0223", "221/259", "0012". */
const NUMBER_LINE = /^(?:[CURMSLTBP]\s+)?0*(\d{1,4}[a-z]?)(?:\s*\/\s*\d{1,4})?(?:\s+[CURMSLTBP])?$/
/** A number over a set size inside a longer line, as 2003–2014 cards print it: "…Wizards of the Coast 66/350". */
const NUMBER_OF_TOTAL = /(?:^|\D)0*(\d{1,4}[a-z]?)\s*\/\s*(\d{2,4})(?!\d)/
/** A copyright line: "© 1995 Wizards…", "TM & © 1993-2009 Wizards…", "™ & © 2025 Wizards…". */
const COPYRIGHT = /wizards|©|™/i
const YEAR = /(?<!\d)(199\d|20[0-4]\d)(?!\d)/g

/** True when OCR read some words. A capture without any is the bare scanning area, not a card. */
export function hasText(ocr: OcrResult): boolean {
  return ocr.lines.some((line) => letters(line.text) >= 3)
}

/** Reads the title, set code, collector number, copyright year, and foil star from OCR lines (spec §5.1.2). */
export function readCard(ocr: OcrResult): CardReading {
  const lines = ocr.lines.filter((l) => l.text.trim() !== '')
  const top = Math.min(...lines.map((l) => l.box.y))
  const height = Math.max(...lines.map((l) => l.box.y + l.box.h)) - top
  const at = (box: OcrLine['box']) => (lines.length < 2 || height <= 0 ? middle(box) : (middle(box) - top) / height)
  let title: string | null = null
  for (const line of lines) {
    if (at(line.box) > TITLE_BAND || letters(line.text) < 3) continue
    if (title === null || letters(line.text) > letters(title)) title = line.text.trim()
  }
  let setCode: string | null = null
  let foil = false
  let collectorNumber: string | null = null
  let numberOfTotal: string | null = null
  let year: number | null = null
  const bottom = lines.filter((l) => at(l.box) >= COLLECTOR_BAND).sort((a, b) => a.box.y - b.box.y || a.box.x - b.box.x)
  for (const line of bottom) {
    const text = line.text.trim()
    const set = SET_LINE.exec(text)
    if (set && setCode === null && /[A-Z]/.test(set[1]!)) {
      setCode = set[1]!.toLowerCase()
      foil = set[2] === '★'
    }
    if (COPYRIGHT.test(text)) for (const [y] of text.matchAll(YEAR)) year = Math.max(year ?? 0, Number(y))
    if (line.box.x > PT_BOX_X) continue
    const number = NUMBER_LINE.exec(text)
    if (number && collectorNumber === null) collectorNumber = number[1]!
    // A set holds at least 20 cards, and the number is at most the set size, unlike power/toughness ("3/3").
    const ofTotal = NUMBER_OF_TOTAL.exec(text)
    const total = Number(ofTotal?.[2])
    if (ofTotal && numberOfTotal === null && parseInt(ofTotal[1]!, 10) <= total && total >= 20) numberOfTotal = ofTotal[1]!
  }
  const texts = lines.map((l) => l.text)
  return { title, setCode, collectorNumber: collectorNumber ?? numberOfTotal, year, foil, texts }
}

/** A printing, as the matcher sees it. */
export interface CardRef {
  id: string
  oracleId: string
  name: string
  faceNames: string[]
  setCode: string
  collectorNumber: string
  releasedAt: string
  lang: string
}

/** The card data the matcher needs; the server answers from SQLite, tests from a list. */
export interface CardLookups {
  /** Printings with this set code and collector number. */
  bySetAndNumber(setCode: string, collectorNumber: string): CardRef[]
  /** Every set code in the card data. */
  setCodes(): readonly string[]
  /** The card identity a name means exactly (its full name or a face's, ignoring case and punctuation), or null. */
  findName(name: string): string | null
  /** Card identities whose name (or a face's) scores at least `threshold` against a normalized name, best first. */
  searchNames(normalized: string, threshold: number): Array<{ oracleId: string; score: number }>
  /** Every printing of a card identity, the default printing first. */
  printings(oracleId: string): CardRef[]
}

export interface ScoredCard {
  card: CardRef
  score: number
}

/**
 * What a scan found:
 * - `confident`: the card and its printing.
 * - `printing`: the card is certain but its printing isn't; `card` is the likeliest printing.
 * - `unsure`: not certain which card this is; `candidates` lists the likeliest, best first.
 */
export interface MatchDecision {
  outcome: 'confident' | 'printing' | 'unsure'
  card: CardRef | null
  confidence: number | null
  candidates: ScoredCard[]
  reading: CardReading
}

/** Best similarity between a printing's names (full and each face) and any of the texts. */
function nameSimilarity(card: CardRef, texts: readonly string[]): number {
  const names = [card.name, ...card.faceNames].map(normalizeName).filter((n) => n !== '')
  let best = 0
  for (const text of texts) {
    const key = normalizeName(text)
    if (key === '') continue
    for (const name of names) best = Math.max(best, jaroWinkler(key, name))
  }
  return best
}

const withoutSuffix = (number: string) => number.replace(/[a-z]$/, '')

/** Same length, one character different. */
function oneApart(a: string, b: string): boolean {
  if (a.length !== b.length) return false
  let differences = 0
  for (let i = 0; i < a.length; i++) if (a[i] !== b[i]) differences++
  return differences === 1
}
const round = (score: number) => Math.round(score * 1000) / 1000

/** Decides which card a reading is (spec §5.1.2). */
export function decide(reading: CardReading, lookups: CardLookups): MatchDecision {
  const { title, setCode, collectorNumber, year } = reading
  // 1. The set code and collector number name a printing, and its name is printed on the card. A set code that
  // names no such printing may be misread by one character (TDM read as TOM), so set codes one character away are
  // tried too; the name check keeps that safe.
  if (setCode && collectorNumber) {
    const numbers = [...new Set([collectorNumber, withoutSuffix(collectorNumber)])]
    const find = (codes: readonly string[]) =>
      codes.flatMap((code) => numbers.flatMap((n) => lookups.bySetAndNumber(code, n)))
    let hits = find([setCode])
    if (hits.length === 0) hits = find(lookups.setCodes().filter((code) => oneApart(code, setCode)))
    const texts = title ? [title, ...reading.texts] : reading.texts
    const best = hits
      .map((card) => ({ card, score: round(nameSimilarity(card, texts)) }))
      .sort((a, b) => b.score - a.score)[0]
    if (best && best.score >= SET_NUMBER_NAME_SIMILARITY) {
      return { outcome: 'confident', card: best.card, confidence: best.score, candidates: [best], reading }
    }
  }
  // 2. The title names one card: exactly, or clearly more closely than any other card.
  const key = title ? normalizeName(title) : ''
  const ranked = key === '' ? [] : lookups.searchNames(key, CANDIDATE_SIMILARITY)
  const exact = title ? lookups.findName(title) : null
  if (exact) ranked.unshift({ oracleId: exact, score: 1 })
  const seen = new Set<string>()
  const candidates: ScoredCard[] = []
  for (const { oracleId, score } of ranked) {
    if (seen.has(oracleId) || candidates.length === MAX_CANDIDATES) continue
    seen.add(oracleId)
    const card = lookups.printings(oracleId)[0]
    if (card) candidates.push({ card, score: round(score) })
  }
  const [best, next] = candidates
  const clearlyBest = best && best.score >= NAME_SIMILARITY && (!next || best.score - next.score >= NAME_GAP)
  if (!best || (exact !== best.card.oracleId && !clearlyBest)) {
    return { outcome: 'unsure', card: best?.card ?? null, confidence: best?.score ?? null, candidates, reading }
  }
  // 3. Which printing. An English title means an English card, so only English printings count when there are any.
  // The set code, collector number, and copyright year read each narrow them; one left is the printing.
  const printings = lookups.printings(best.card.oracleId)
  const english = printings.filter((p) => p.lang === 'en')
  let pool = english.length > 0 ? english : printings
  const narrow = (keep: (p: CardRef) => boolean) => {
    const left = pool.filter(keep)
    if (left.length > 0) pool = left
  }
  if (setCode) narrow((p) => p.setCode === setCode)
  if (collectorNumber) narrow((p) => [collectorNumber, withoutSuffix(collectorNumber)].includes(p.collectorNumber))
  if (year) narrow((p) => [year, year + 1].includes(Number(p.releasedAt.slice(0, 4))))
  const outcome = pool.length === 1 ? 'confident' : 'printing'
  return { outcome, card: pool[0]!, confidence: best.score, candidates, reading }
}
```

```ts
import { createFuzzySearch, type FuzzySearch } from '../cards/fuzzy.ts'
import { cardNameIndex, type CardNameIndex } from '../cards/names.ts'
import { DEFAULT_PRINTING_ORDER } from '../cards/repo.ts'
import type { DB } from '../db/index.ts'
import { getMeta } from '../db/meta.ts'
import type { CardLookups, CardRef } from './matcher.ts'

interface RefRow {
  id: string
  oracle_id: string
  name: string
  face_names: string
  set_code: string
  collector_number: string
  released_at: string
  lang: string
}

const toRef = (r: RefRow): CardRef => ({
  id: r.id,
  oracleId: r.oracle_id,
  name: r.name,
  faceNames: r.face_names.split('\n'),
  setCode: r.set_code,
  collectorNumber: r.collector_number,
  releasedAt: r.released_at,
  lang: r.lang,
})

const REF_COLUMNS = 'id, oracle_id, name, face_names, set_code, collector_number, released_at, lang'

/**
 * The matcher's card data from SQLite. The name index and set codes are loaded on first use (about 70 ms) and again
 * when the card data changes.
 */
export function createCardLookups(db: DB): CardLookups {
  const bySetAndNumber = db.prepare(`SELECT ${REF_COLUMNS} FROM cards WHERE set_code = ? AND collector_number = ?`)
  const printings = db.prepare(
    `SELECT ${REF_COLUMNS} FROM cards WHERE oracle_id = ? ORDER BY ${DEFAULT_PRINTING_ORDER}`,
  )
  const setCodes = db.prepare('SELECT DISTINCT set_code FROM cards').pluck()
  let cached: { version: string; index: CardNameIndex; search: FuzzySearch; sets: string[] } | null = null
  const current = () => {
    const version = `${getMeta(db, 'bulk_updated_at')}|${getMeta(db, 'card_names_version')}`
    if (cached?.version !== version) {
      const index = cardNameIndex(db)
      cached = { version, index, search: createFuzzySearch(index.keys), sets: setCodes.all() as string[] }
    }
    return cached
  }
  return {
    bySetAndNumber: (setCode, collectorNumber) => (bySetAndNumber.all(setCode, collectorNumber) as RefRow[]).map(toRef),
    setCodes: () => current().sets,
    findName: (name) => current().index.find(name)?.oracleId ?? null,
    searchNames: (normalized, threshold) => current().search(normalized, threshold),
    printings: (oracleId) => (printings.all(oracleId) as RefRow[]).map(toRef),
  }
}
```

```ts
/** A gray JPEG of the given size, made by writing a BMP and converting it with macOS's sips. */
function jpeg(width: number, height: number): string {
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'binder-claude-'))
  const row = Math.ceil((width * 3) / 4) * 4
  const bmp = Buffer.alloc(54 + row * height)
  bmp.fill(0x80, 54) // gray pixels after the headers
  bmp.write('BM', 0)
  bmp.writeUInt32LE(bmp.length, 2)
  bmp.writeUInt32LE(54, 10)
  bmp.writeUInt32LE(40, 14)
  bmp.writeInt32LE(width, 18)
  bmp.writeInt32LE(height, 22)
  bmp.writeUInt16LE(1, 26)
  bmp.writeUInt16LE(24, 28)
  bmp.writeUInt32LE(row * height, 34)
  fs.writeFileSync(path.join(dir, 'in.bmp'), bmp)
  execFileSync('sips', ['-s', 'format', 'jpeg', path.join(dir, 'in.bmp'), '--out', path.join(dir, 'photo.jpg')], { stdio: 'ignore' })
  return path.join(dir, 'photo.jpg')
}
```

```ts
import fs from 'node:fs'

const KEY_LINE = /^\s*ANTHROPIC_API_KEY\s*=\s*(.*?)\s*$/

/**
 * The Anthropic API key, kept in the project's `.env` file (spec §3.1, §5.6). Other lines in the file are left as
 * they are. The file is written with mode 600, so only the owner can read it.
 */
export interface KeyStore {
  /** The saved key, or null. */
  read(): string | null
  /** Saves a key, or removes it with null. */
  write(key: string | null): void
}

export function createKeyStore(envPath: string): KeyStore {
  const lines = () => (fs.existsSync(envPath) ? fs.readFileSync(envPath, 'utf8').split('\n') : [])
  return {
    read() {
      for (const line of lines()) {
        const value = KEY_LINE.exec(line)?.[1]?.replace(/^(['"])(.*)\1$/, '$2')
        if (value) return value
      }
      return null
    },
    write(key) {
      const kept = lines().filter((line) => !KEY_LINE.test(line))
      while (kept.length > 0 && kept.at(-1) === '') kept.pop()
      if (key !== null) kept.push(`ANTHROPIC_API_KEY=${key}`)
      const text = kept.length > 0 ? `${kept.join('\n')}\n` : ''
      fs.writeFileSync(envPath, text, { mode: 0o600 })
      fs.chmodSync(envPath, 0o600) // an existing file keeps its mode on write
    },
  }
}
```

```ts
import type { KeyStore } from './key-store.ts'

/** The model for the scan fallback (spec §2, §5.1.2). */
export const AI_MODEL = 'claude-opus-5'

/** The Anthropic client for the saved API key; the Settings page changes the key (spec §5.6). */
export interface AiClient {
  /** A client for the saved key, or null when there's none. */
  get(): Anthropic | null
  status(): AiKeyStatus
  /** Saves a key (or removes it with null) and makes a new client for it. */
  setKey(key: string | null): AiKeyStatus
  /** Checks that a key (by default the saved one) works, with a request that costs nothing. */
  test(key?: string): Promise<void>
}

export function createAiClient(store: KeyStore, make = (apiKey: string) => new Anthropic({ apiKey })): AiClient {
  let key = store.read()
  let client = key ? make(key) : null
  const status = (): AiKeyStatus => ({ configured: key !== null, hint: key ? key.slice(-4) : null })
  return {
    get: () => client,
    status,
    setKey(next) {
      store.write(next)
      key = next
      client = next ? make(next) : null
      return status()
    },
    async test(candidate) {
      const tester = candidate ? make(candidate) : client
      if (!tester) throw new Error('No API key is saved')
      await tester.models.retrieve(AI_MODEL)
    },
  }
}

/** A short explanation of an Anthropic API failure, for toasts and scan errors (spec §6). */
export function describeAiError(err: unknown): string {
  if (err instanceof Anthropic.AuthenticationError) return 'The API key was refused'
  if (err instanceof Anthropic.PermissionDeniedError) return "The API key isn't allowed to use this model"
  if (err instanceof Anthropic.RateLimitError) return 'Anthropic is rate-limiting requests; try again shortly'
  if (err instanceof Anthropic.APIConnectionError) return "Couldn't reach Anthropic; check the internet connection"
  if (err instanceof Anthropic.APIError) return `Anthropic answered with an error (${err.status ?? '?'}): ${err.message}`
  return err instanceof Error ? err.message : String(err)
}
```

```ts
  type: 'object',

    set_code: nullableString('The set code on the collector line at the bottom left, such as "M15"; null if not printed'),
    collector_number: nullableString('The collector number on the collector line, such as "145"; null if not printed'),
    looks_foil: { type: 'boolean', description: 'True if the card looks foil (shiny) or has a ★ on its collector line' },
    confidence: { type: 'number', description: 'How sure you are of the name, from 0 to 1' },
  },
  required: ['name', 'set_code', 'collector_number', 'looks_foil', 'confidence'],
  additionalProperties: false,
} as const

const SYSTEM =
  'You identify Magic: The Gathering cards from photos taken for a collection scanner. Read the name from the ' +
  'title bar, and the set code and collector number from the collector line at the bottom left when the card ' +
  'prints them (older cards do not). Answer in English even if the card is printed in another language.'

/** The longest edge of the image Claude sees (spec §5.1.2). */
export const CLAUDE_MAX_EDGE = 1024

/** Asks Claude which card a photo shows. */
export interface CardIdentifier {
  identify(imagePath: string): Promise<ClaudeReading>
}

const execFileAsync = promisify(execFile)

/** The photo as base64 JPEG, shrunk with macOS's `sips` to CLAUDE_MAX_EDGE on its long edge if it's larger. */
async function photoForClaude(imagePath: string): Promise<string> {
  const { stdout } = await execFileAsync('sips', ['-g', 'pixelWidth', '-g', 'pixelHeight', imagePath])
  const edge = Math.max(...[...stdout.matchAll(/pixel(?:Width|Height): (\d+)/g)].map((m) => Number(m[1])))
  if (edge <= CLAUDE_MAX_EDGE) return fs.readFileSync(imagePath).toString('base64')
  const small = path.join(os.tmpdir(), `binder-scan-${process.pid}-${Date.now()}.jpg`)
  try {
    await execFileAsync('sips', ['-Z', String(CLAUDE_MAX_EDGE), imagePath, '--out', small])
    return fs.readFileSync(small).toString('base64')
  } finally {
    fs.rmSync(small, { force: true })
  }
}

/**
 * One request per photo to the scan model at low effort, with structured output (spec §5.1.2). Server-side refusal
 * fallbacks are on, so a declined request is retried on the model Anthropic recommends for it.
 */
export function createClaudeIdentifier(client: Anthropic): CardIdentifier {
  return {
    async identify(imagePath) {
      const data = await photoForClaude(imagePath)
      const response = await client.beta.messages.create(
        {
          model: AI_MODEL,
          max_tokens: 4096,
          betas: ['server-side-fallback-2026-07-01'],
          fallbacks: 'default',
          output_config: { effort: 'low', format: { type: 'json_schema', schema: READING_SCHEMA } },
          system: SYSTEM,
          messages: [
            {
              role: 'user',
              content: [
                { type: 'image', source: { type: 'base64', media_type: 'image/jpeg', data } },
                { type: 'text', text: 'Which card is this?' },
              ],
            },
          ],
        },
        { timeout: 60_000 },
      )
      if (response.stop_reason === 'refusal') throw new Error('Claude declined to identify this photo')
      if (response.stop_reason === 'max_tokens') throw new Error("Claude's answer was cut off")
      const text = response.content.find((block) => block.type === 'text')?.text ?? ''
      let parsed: unknown
      try {
        parsed = JSON.parse(text)
      } catch {
        throw new Error("Claude's answer wasn't the expected JSON")
      }
      const reading = ClaudeReading.safeParse(parsed)
      if (!reading.success) throw new Error("Claude's answer wasn't the expected JSON")
      return reading.data
    },
  }
}
```

### Task 5: The scan queue: storage, identification, and routes

Spec §5.1.2's pipeline:

1. `POST /api/scan` saves the capture as `<data>/scans/<id>.jpg`, queues it, and answers at once.
2. The worker reads queued scans with OCR, two at a time. The one helper process takes them in turn.
3. A **confident** match is ready. A certain card with an uncertain printing goes to review ("Check the printing"),
   or is ready when `scanAcceptUncertainPrinting` is on.
4. Anything else goes to Claude when a key is set, two at a time. Claude's answer is checked against the card data
   like an OCR reading, and counts only when Claude reports at least 0.5 confidence. Without a key, or when OCR or
   Claude fails, the scan goes to review with its candidates and the error.
5. A ★ on the collector line, or Claude's `looks_foil`, starts the scan as foil when the printing comes in foil;
   otherwise it starts in the default finish. With auto-commit on, a confident scan goes straight into the
   collection.

Two additions spec §4.1 doesn't list, in migration 003:

- `reason` ('printing' or 'unsure'), so the queue can say why a scan needs a look.
- `auto`: auto mode (Task 7) also captures the bare scanning area once a card is lifted, and those captures, with no
  text at all, are dropped. A manual capture is never dropped; with no text it goes to review with "No text found in
  the capture".

A restart puts scans left mid-identification back in the queue. Retry sends a review scan through again, for
example after adding an API key. Commit adds each ready scan's quantity of its printing and finish to the collection
(M3's `adjustCopies`), then deletes its image.

```ts
export type ScanUpdate = ScanItem | 'no_scan' | 'busy' | 'no_card' | 'bad_finish'

/**
 * Edits a scan in the queue (spec §5.1.3). Choosing a card makes it confident and marks it as picked by hand; a
 * finish the printing doesn't come in is refused, and a new printing keeps the finish only if it comes in it.
 */
export function updateScan(db: DB, id: number, patch: ScanPatch, now = new Date()): ScanUpdate {
  return db.transaction((): ScanUpdate => {
    const row = getRow(db, id)
    if (!row || row.status === 'committed' || row.status === 'discarded') return 'no_scan'
    if (row.status === 'queued' || row.status === 'identifying') return 'busy'
    const next = { ...row }
    if (patch.cardId !== undefined) {
      if (!db.prepare('SELECT 1 FROM cards WHERE id = ?').get(patch.cardId)) return 'no_card'
      next.card_id = patch.cardId
      next.finish = finishFor(db, patch.cardId, row.finish)
      next.method = 'manual'
      next.status = 'confident'
      next.reason = null
    }
    if (patch.finish !== undefined) {
      if (!next.card_id || finishFor(db, next.card_id, patch.finish) !== patch.finish) return 'bad_finish'
      next.finish = patch.finish
    }
    if (patch.quantity !== undefined) next.quantity = patch.quantity
    if (patch.confirm) {
      if (!next.card_id) return 'no_card'
      next.status = 'confident'
      next.reason = null
    }
    db.prepare(
      `UPDATE scan_items SET card_id = @card_id, finish = @finish, method = @method, status = @status, reason = @reason,
         quantity = @quantity, updated_at = @at WHERE id = @id`,
    ).run({ ...next, at: now.toISOString() })
    return toItem(db, getRow(db, id)!)
  })()
}

  db.prepare("UPDATE scan_items SET status = 'discarded', updated_at = ? WHERE id = ?").run(now.toISOString(), id)

  return true
}

/** Sends a review scan through identification again, for example after adding an API key. */

  const changed = db
    .prepare("UPDATE scan_items SET status = 'queued', error = NULL, updated_at = ? WHERE id = ? AND status = 'review'")
    .run(now.toISOString(), id).changes
  return changed === 1 ? getScanItem(db, id) : null
}

/**
 * Adds confident scans to the collection (spec §5.1.3), all of them or just those with the given ids: each adds its
 * quantity of its printing in its finish. They become committed and their images are deleted.
 */
export function commitScans(
  db: DB,
  scansDir: string,
  ids?: readonly number[],
  now = new Date(),
): { items: number; copies: number } {
  const rows = db.transaction(() => {
    const all = db
      .prepare("SELECT * FROM scan_items WHERE status = 'confident' AND card_id IS NOT NULL ORDER BY id")
      .all() as ScanRow[]
    const confident = all.filter((row) => !ids || ids.includes(row.id))
    const done = db.prepare("UPDATE scan_items SET status = 'committed', updated_at = ? WHERE id = ?")
    for (const row of confident) {
      adjustCopies(db, row.card_id!, row.finish, row.quantity, now)
      done.run(now.toISOString(), row.id)
    }
    return confident
  })()
  for (const row of rows) deleteImage(scansDir, row)
  return { items: rows.length, copies: rows.reduce((sum, row) => sum + row.quantity, 0) }
}
```

```ts
export const CLAUDE_MIN_CONFIDENCE = 0.5

export interface ScanWorkerDeps {
  db: DB
  scansDir: string
  ocr: OcrClient
  lookups: CardLookups
  /** The Claude fallback, or null when no API key is set. */
  claude: () => CardIdentifier | null
  now?: () => Date
}

export interface ScanWorker {
  /** Starts identifying queued scans; call it after queueing one. */
  kick(): void
  /** Resolves once nothing is queued or being identified. */
  idle(): Promise<void>
  /** Queues again the scans a restart interrupted, then starts. */
  recover(): void
}

/** A collector number as the card data writes it: "0223" and "223/274" both give "223". */
const collectorNumber = (value: string | null) =>
  value?.trim().toLowerCase().replace(/\/.*$/, '').replace(/^0+(?=\d)/, '') || null

const candidateIds = (candidates: readonly ScoredCard[]) =>
  candidates.map((c) => ({ cardId: c.card.id, score: c.score }))

interface ClaudeJob {
  row: ScanRow
  /** What OCR made of it (null if OCR failed), and why OCR failed. */
  decision: MatchDecision | null
  ocrError: string | null
  ocrJson: string | null
}

/**
 * Identifies queued scans (spec §5.1.2): OCR and the matcher first; what they can't settle goes to Claude when an
 * API key is set, and otherwise to review. A confident scan is committed straight away when auto-commit is on.
 */
export function createScanWorker(deps: ScanWorkerDeps): ScanWorker {
  const { db, lookups } = deps
  const now = deps.now ?? (() => new Date())
  let ocrRunning = 0
  let claudeRunning = 0
  const claudeQueue: ClaudeJob[] = []
  let waiting: Array<() => void> = []

  function save(row: ScanRow, result: Omit<ScanResult, 'finish'> & { foil: boolean }) {
    const settings = getSettings(db)
    const preferred = result.foil ? 'foil' : settings.scanDefaultFinish
    const finish = result.cardId ? finishFor(db, result.cardId, preferred) : settings.scanDefaultFinish
    const saved = saveScanResult(db, row.id, { ...result, finish }, now())
    if (saved && result.status === 'confident' && settings.scanAutoCommit) {
      commitScans(db, deps.scansDir, [row.id], now())
    }
  }

  /** Saves a decision that needs no Claude: confident, or a printing that's uncertain. */
  function saveDecision(
    row: ScanRow,
    decision: MatchDecision,
    method: 'ocr' | 'claude',
    extra: { foil: boolean; ocrJson: string | null },
  ) {
    const accept = decision.outcome === 'printing' && getSettings(db).scanAcceptUncertainPrinting
    const confident = decision.outcome === 'confident' || accept
    save(row, {
      status: confident ? 'confident' : 'review',
      method,
      reason: confident ? null : decision.outcome === 'printing' ? 'printing' : 'unsure',
      cardId: decision.card?.id ?? null,
      confidence: decision.confidence,
      candidates: candidateIds(decision.candidates),
      error: null,
      ...extra,
    })
  }

  async function readScan(row: ScanRow) {
    const file = scanImageFile(deps.scansDir, row)
    let decision: MatchDecision | null = null
    let ocrError: string | null = null
    let ocrJson: string | null = null
    try {
      if (!file) throw new Error('The scan has no image')
      const ocr = await deps.ocr.recognize(file)
      if (!hasText(ocr) && row.auto === 1) {
        // Auto mode also captures the bare scanning area once a card is lifted: nothing to keep.
        discardScan(db, deps.scansDir, row.id, now())
        return
      }
      ocrJson = JSON.stringify(ocr)
      decision = decide(readCard(ocr), lookups)
      if (!hasText(ocr)) ocrError = 'No text found in the capture'
    } catch (err) {
      ocrError = `OCR failed: ${err instanceof Error ? err.message : String(err)}`
    }
    if (decision && decision.outcome !== 'unsure') {
      saveDecision(row, decision, 'ocr', { foil: decision.reading.foil, ocrJson })
    } else if (deps.claude()) {
      claudeQueue.push({ row, decision, ocrError, ocrJson })
    } else {
      save(row, {
        status: 'review',
        method: 'ocr',
        reason: 'unsure',
        cardId: decision?.card?.id ?? null,
        confidence: decision?.confidence ?? null,
        candidates: decision ? candidateIds(decision.candidates) : [],
        error: ocrError,
        foil: false,
        ocrJson,
      })
    }
  }

  async function askClaude({ row, decision, ocrError, ocrJson }: ClaudeJob) {
    const identifier = deps.claude()
    const file = scanImageFile(deps.scansDir, row)
    try {
      if (!identifier || !file) throw new Error('No API key is set')
      const answer = await identifier.identify(file)
      const checked = decide(
        {
          title: answer.name,
          setCode: answer.set_code?.trim().toLowerCase() || null,
          collectorNumber: collectorNumber(answer.collector_number),
          year: null,
          foil: answer.looks_foil,
          texts: [answer.name],
        },
        lookups,
      )
      if (checked.outcome !== 'unsure' && answer.confidence >= CLAUDE_MIN_CONFIDENCE) {
        saveDecision(row, checked, 'claude', { foil: answer.looks_foil, ocrJson })
        return
      }
      const candidates = [...checked.candidates, ...(decision?.candidates ?? [])]
      const unique = candidates.filter((c, i) => candidates.findIndex((d) => d.card.oracleId === c.card.oracleId) === i)
      save(row, {
        status: 'review',
        method: 'claude',
        reason: 'unsure',
        cardId: unique[0]?.card.id ?? null,
        confidence: checked.confidence,
        candidates: candidateIds(unique.slice(0, 5)),
        error: null,
        foil: answer.looks_foil,
        ocrJson,
      })
    } catch (err) {
      save(row, {
        status: 'review',
        method: 'ocr',
        reason: 'unsure',
        cardId: decision?.card?.id ?? null,
        confidence: decision?.confidence ?? null,
        candidates: decision ? candidateIds(decision.candidates) : [],
        error: [ocrError, `Claude couldn't identify it: ${describeAiError(err)}`].filter(Boolean).join('. '),
        foil: false,
        ocrJson,
      })
    }
  }

  /** Runs a stage, turning an unexpected failure into a review scan so no capture is ever lost. */
  async function guarded(row: ScanRow, stage: () => Promise<void>) {
    try {
      await stage()
    } catch (err) {
      saveScanResult(
        db,
        row.id,
        {
          status: 'review', method: 'ocr', reason: 'unsure', cardId: null, finish: getSettings(db).scanDefaultFinish,
          confidence: null, candidates: [], error: err instanceof Error ? err.message : String(err), ocrJson: null,
        },
        now(),
      )
    }
  }

  function pump() {
    while (ocrRunning < OCR_CONCURRENCY) {
      const row = claimNextScan(db, now())
      if (!row) break
      ocrRunning++
      void guarded(row, () => readScan(row)).finally(() => {
        ocrRunning--
        pump()
      })
    }
    while (claudeRunning < CLAUDE_CONCURRENCY && claudeQueue.length > 0) {
      const job = claudeQueue.shift()!
      claudeRunning++
      void guarded(job.row, () => askClaude(job)).finally(() => {
        claudeRunning--
        pump()
      })
    }
    if (ocrRunning === 0 && claudeRunning === 0) {
      for (const resolve of waiting) resolve()
      waiting = []
    }
  }

  return {
    kick: pump,
    idle: () =>
      ocrRunning === 0 && claudeRunning === 0 ? Promise.resolve() : new Promise((resolve) => waiting.push(resolve)),
    recover() {
      requeueInterrupted(db)
      pump()
    },
  }
}
```

```ts
/** /api/scan (spec §5.1): capture, the queue, edits, and commit. */
export function scanRoutes(deps: { db: DB; scanner: ScanService }): Hono {
  const { db, scanner } = deps
  const routes = new Hono()

  routes.post(
    '/',
    bodyLimit({
      maxSize: MAX_SCAN_BYTES,
      onError: () => {
        throw new ApiError(413, 'too_large', `A capture can be at most ${MAX_SCAN_BYTES / 1024 / 1024} MB`)
      },
    }),
    async (c) => {
      const bytes = new Uint8Array(await c.req.arrayBuffer())
      if (!isJpeg(bytes)) throw new ApiError(400, 'bad_request', 'A capture must be a JPEG image')
      const item = addScan(db, scanner.scansDir, bytes, c.req.query('auto') === '1')
      scanner.worker.kick()
      return c.json(item, 201)
    },
  )

  routes.get('/items', (c) => c.json({ items: listScanItems(db) }))

  routes.get('/items/:id/image', (c) => {
    const row = db.prepare('SELECT image_path FROM scan_items WHERE id = ?').get(scanId(c.req.param('id'))) as
      | { image_path: string | null }
      | undefined
    const file = row && scanImageFile(scanner.scansDir, row)
    if (!file || !fs.existsSync(file)) throw new ApiError(404, 'not_found', 'Scan image not found')
    const headers = { 'Content-Type': 'image/jpeg', 'Cache-Control': 'private, max-age=3600' }
    return c.body(fs.readFileSync(file), 200, headers)
  })

  routes.patch('/items/:id', async (c) => {
    const id = scanId(c.req.param('id'))
    const result = updateScan(db, id, parseWith(Patch, await readJson(c.req)))
    if (result === 'no_scan') throw new ApiError(404, 'not_found', 'Scan not found')
    if (result === 'busy') throw new ApiError(409, 'busy', "This scan is still being identified")
    if (result === 'no_card') throw new ApiError(400, 'no_card', 'Choose a card first')
    if (result === 'bad_finish') throw new ApiError(400, 'bad_finish', "That printing doesn't come in that finish")
    return c.json(result)
  })

  routes.delete('/items/:id', (c) => {
    const discarded = discardScan(db, scanner.scansDir, scanId(c.req.param('id')))
    if (!discarded) throw new ApiError(404, 'not_found', 'Scan not found')
    return c.body(null, 204)
  })

  routes.post('/items/:id/retry', (c) => {
    const id = scanId(c.req.param('id'))
    const item = retryScan(db, id)
    if (!item) {
      if (!getScanItem(db, id)) throw new ApiError(404, 'not_found', 'Scan not found')
      throw new ApiError(409, 'busy', 'Only scans in review can be identified again')
    }
    scanner.worker.kick()
    return c.json(item)
  })

  routes.post('/commit', (c) => c.json(commitScans(db, scanner.scansDir)))

  return routes
}
```

```ts
/** A card is 63 × 88 mm (spec §5.1.1). */
export const CARD_ASPECT = 63 / 88

export interface Rect {
  x: number
  y: number
  width: number
  height: number
}

/** The card-shaped guide in a video frame: centered, as tall as `fill` of the frame (narrower if the frame is). */
export function guideRect(frameWidth: number, frameHeight: number, fill = 0.82): Rect {
  let height = frameHeight * fill
  let width = height * CARD_ASPECT
  if (width > frameWidth * fill) {
    width = frameWidth * fill
    height = width / CARD_ASPECT
  }
  return { x: (frameWidth - width) / 2, y: (frameHeight - height) / 2, width, height }
}

/**
 * What a capture keeps: the guide plus a margin on every side (clamped to the frame), so a card placed a little off
 * the guide is still whole. The server finds the card's text within it.
 */
export function captureRect(guide: Rect, frameWidth: number, frameHeight: number, margin = 0.08): Rect {
  const dx = guide.width * margin
  const dy = guide.height * margin
  const x = Math.max(0, guide.x - dx)
  const y = Math.max(0, guide.y - dy)
  return {
    x,
    y,
    width: Math.min(frameWidth, guide.x + guide.width + dx) - x,
    height: Math.min(frameHeight, guide.y + guide.height + dy) - y,
  }
}

/** Mean absolute difference of the red, green, and blue values of two same-size RGBA frames, from 0 to 255. */
export function frameDifference(a: Uint8ClampedArray, b: Uint8ClampedArray): number {
  if (a.length !== b.length || a.length === 0) return 255
  let total = 0
  for (let i = 0; i < a.length; i += 4) {
    total += Math.abs(a[i]! - b[i]!) + Math.abs(a[i + 1]! - b[i + 1]!) + Math.abs(a[i + 2]! - b[i + 2]!)
  }
  return total / ((a.length / 4) * 3)
}

/** How often auto mode samples the frame, and how long it must hold still (spec §5.1.1). */
export const SAMPLE_MS = 150
export const STABLE_MS = 600
/** A difference between samples above this is a change: a card placed, lifted, or swapped. */
export const CHANGE_THRESHOLD = 12
/** A difference at or below this counts as holding still (camera noise is about 1–3). */
export const STILL_THRESHOLD = 4

/**
 * Auto mode (spec §5.1.1): after a change, waits for the frame to hold still for STABLE_MS, captures once, then
 * waits for the next change. Feed it each sample's difference from the previous sample; it answers true when it's
 * time to capture.
 */
export function createAutoCapture(options: { change?: number; still?: number; stableMs?: number } = {}) {
  const change = options.change ?? CHANGE_THRESHOLD
  const still = options.still ?? STILL_THRESHOLD
  const stableMs = options.stableMs ?? STABLE_MS
  let armed = false
  let stillSince: number | null = null
  return {
    /** Whether a change has happened since the last capture. */
    get armed() {
      return armed
    },
    sample(difference: number, now: number): boolean {
      if (difference > change) {
        armed = true
        stillSince = null
        return false
      }
      if (!armed) return false
      if (difference > still) {
        stillSince = null
        return false
      }
      stillSince ??= now
      if (now - stillSince < stableMs) return false
      armed = false
      stillSince = null
      return true
    },
    reset() {
      armed = false
      stillSince = null
    },
  }
}
```

```tsx
        if (videoRef.current) videoRef.current.srcObject = s
        setError(null)
      })
      .catch((err: unknown) => setError(describeCameraError(err)))
    return () => {
      cancelled = true
      for (const track of stream?.getTracks() ?? []) track.stop()
    }
  }, [chosen?.deviceId])

    const video = videoRef.current
    if (!video || video.videoWidth === 0) return
    const { videoWidth: w, videoHeight: h } = video
    const r = captureRect(guideRect(w, h), w, h)
    const canvas = document.createElement('canvas')
    canvas.width = Math.round(r.width)
    canvas.height = Math.round(r.height)
    canvas.getContext('2d')?.drawImage(video, r.x, r.y, r.width, r.height, 0, 0, canvas.width, canvas.height)
    canvas.toBlob(
      (jpeg) => {
        if (!jpeg) return
        onCapture(jpeg, auto)
        beep(audio.current)
        setFlashes((n) => n + 1)
      },
      'image/jpeg',
      0.92,
    )

  }, [])

    canvas.height = SAMPLE_SIZE.height

      const g = guideRect(video.videoWidth, video.videoHeight)
      ctx.drawImage(video, g.x, g.y, g.width, g.height, 0, 0, SAMPLE_SIZE.width, SAMPLE_SIZE.height)
      const frame = ctx.getImageData(0, 0, SAMPLE_SIZE.width, SAMPLE_SIZE.height).data
      if (previous && auto.sample(frameDifference(previous, frame), performance.now())) captureRef.current(true)
      previous = frame
    }, SAMPLE_MS)
    return () => clearInterval(timer)
  }, [mode, size])

  const guide = size ? guideRect(size.width, size.height) : null
  const noPhone = devices !== null && !devices.some((d) => /iphone/i.test(d.label))
  const button = (active: boolean) =>
    `rounded-md px-3 py-1 text-sm ${active ? 'bg-stone-700 text-stone-50' : 'text-stone-400 hover:text-stone-100'}`

              {d.label || `Camera ${i + 1}`}
            </option>
          ))}
        </select>
        <div role="radiogroup" aria-label="Capture mode" className="flex rounded-lg border border-stone-800 p-0.5">
          {(['manual', 'auto'] as const).map((m) => (
            <button
              key={m}
              role="radio"
              aria-checked={mode === m}
              onClick={() => {
                setMode(m)
                store(MODE_KEY, m)
              }}
              className={button(mode === m)}
            >
              {m === 'manual' ? 'Manual' : 'Auto'}
            </button>
          ))}
        </div>
      </div>

      <div
        className="relative overflow-hidden rounded-xl border border-stone-800 bg-black"
        style={{ aspectRatio: size ? `${size.width} / ${size.height}` : '4 / 3' }}
      >
        <video

            }}
          />
        )}
        {flashes > 0 && <div key={flashes} aria-hidden className="pointer-events-none absolute inset-0 animate-flash bg-white" />}
```

```swift
// Builds a Motion JPEG "camera feed" for Chrome's fake camera: a card placed in the Scan page's guide,
// lifted, the next card placed, and so on. usage: make-frames <out.mjpeg> <card.jpg>...
import CoreGraphics
import Foundation
import ImageIO
import UniformTypeIdentifiers

let args = CommandLine.arguments
let out = args[1]
let cards = args.dropFirst(2).map { URL(fileURLWithPath: $0) }
let width = 1280, height = 960
let space = CGColorSpace(name: CGColorSpace.sRGB)!

func frame(_ card: CGImage?) -> Data {
  let ctx = CGContext(data: nil, width: width, height: height, bitsPerComponent: 8, bytesPerRow: 0, space: space,
                      bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!
  ctx.setFillColor(CGColor(red: 0.22, green: 0.2, blue: 0.18, alpha: 1))
  ctx.fill(CGRect(x: 0, y: 0, width: width, height: height))
  if let card {
    // A little inside the Scan page's guide, which is card-shaped, centered, and 82% of the frame's height.
    let h = Double(height) * 0.8, w = h * 63 / 88
    ctx.draw(card, in: CGRect(x: (Double(width) - w) / 2, y: (Double(height) - h) / 2, width: w, height: h))
  }
  let data = NSMutableData()
  let dest = CGImageDestinationCreateWithData(data, UTType.jpeg.identifier as CFString, 1, nil)!
  CGImageDestinationAddImage(dest, ctx.makeImage()!, [kCGImageDestinationLossyCompressionQuality: 0.9] as CFDictionary)
  CGImageDestinationFinalize(dest)
  return data as Data
}

let empty = frame(nil)
var video = Data()
for url in cards {
  let source = CGImageSourceCreateWithURL(url as CFURL, nil)!
  let card = frame(CGImageSourceCreateImageAtIndex(source, 0, nil)!)
  for _ in 0..<15 { video.append(empty) }  // half a second of the bare mat at 30 fps
  for _ in 0..<60 { video.append(card) }  // two seconds of the card
}
try video.write(to: URL(fileURLWithPath: out))
```

```ts
// Minimal Chrome DevTools Protocol driver (Node 24 global WebSocket, no dependencies).
import fs from 'node:fs'

export interface Page {
  send<T = any>(method: string, params?: Record<string, unknown>): Promise<T>
  eval<T = any>(expression: string): Promise<T>
  waitFor(expression: string, timeoutMs?: number): Promise<any>
  goto(url: string): Promise<void>
  click(selector: string): Promise<void>
  type(text: string): Promise<void>
  key(key: string, code?: string, keyCode?: number): Promise<void>
  shot(file: string): Promise<void>
  close(): Promise<void>
}

export async function openPage(port = 9333): Promise<Page> {
  const target = (await (await fetch(`http://127.0.0.1:${port}/json/new?about:blank`, { method: 'PUT' })).json()) as { webSocketDebuggerUrl: string; id: string }
  const ws = new WebSocket(target.webSocketDebuggerUrl)
  await new Promise((resolve, reject) => {
    ws.onopen = resolve
    ws.onerror = reject
  })
  let nextId = 0
  const pending = new Map<number, { resolve: (v: any) => void; reject: (e: Error) => void }>()
  ws.onmessage = (event) => {
    const msg = JSON.parse(String(event.data))
    if (msg.id !== undefined && pending.has(msg.id)) {
      const p = pending.get(msg.id)!
      pending.delete(msg.id)
      if (msg.error) p.reject(new Error(`${msg.error.message}`))
      else p.resolve(msg.result)
    }
  }
  const send = <T,>(method: string, params: Record<string, unknown> = {}) =>
    new Promise<T>((resolve, reject) => {
      const id = ++nextId
      pending.set(id, { resolve, reject })
      ws.send(JSON.stringify({ id, method, params }))
    })
  const evaluate = async (expression: string) => {
    const r = await send<any>('Runtime.evaluate', { expression, awaitPromise: true, returnByValue: true })
    if (r.exceptionDetails) throw new Error(`eval failed: ${r.exceptionDetails.exception?.description ?? r.exceptionDetails.text}\n${expression}`)
    return r.result.value
  }
  await send('Page.enable')
  await send('Runtime.enable')
  await send('Emulation.setDeviceMetricsOverride', { width: 1400, height: 1000, deviceScaleFactor: 1, mobile: false })
  const page: Page = {
    send,
    eval: evaluate,
    async waitFor(expression, timeoutMs = 8000) {
      const start = Date.now()
      for (;;) {
        const v = await evaluate(`!!(${expression})`).catch(() => undefined)
        if (v) return v
        if (Date.now() - start > timeoutMs) throw new Error(`timed out waiting for: ${expression}`)
        await new Promise((r) => setTimeout(r, 100))
      }
    },
    async goto(url) {
      await send('Page.navigate', { url })
      await page.waitFor(`document.readyState === 'complete' && !!document.querySelector('#root > *')`)
    },
    async click(selector) {
      const box = await evaluate(`(() => { const el = document.querySelector(${JSON.stringify(selector)}); if (!el) return null; el.scrollIntoView({block: 'center'}); const r = el.getBoundingClientRect(); return {x: r.x + r.width / 2, y: r.y + r.height / 2} })()`)
      if (!box) throw new Error(`no element ${selector}`)
      for (const type of ['mousePressed', 'mouseReleased']) {
        await send('Input.dispatchMouseEvent', { type, x: box.x, y: box.y, button: 'left', clickCount: 1 })
      }
    },
    async type(text) {
      await send('Input.insertText', { text })
    },
    async key(key, code = key, keyCode = 0) {
      if (key === 'Enter') await send('Input.dispatchKeyEvent', { type: 'keyDown', key, code, windowsVirtualKeyCode: 13, text: '\r' })
      else await send('Input.dispatchKeyEvent', { type: 'rawKeyDown', key, code, windowsVirtualKeyCode: keyCode })
      if (key.length === 1) await send('Input.dispatchKeyEvent', { type: 'char', text: key, key })
      await send('Input.dispatchKeyEvent', { type: 'keyUp', key, code, windowsVirtualKeyCode: keyCode })
    },
    async shot(file) {
      const { data } = await send<{ data: string }>('Page.captureScreenshot', { format: 'png' })
      fs.writeFileSync(file, Buffer.from(data, 'base64'))
    },
    async close() {
      ws.close()
      await fetch(`http://127.0.0.1:${port}/json/close/${target.id}`)
    },
  }
  return page
}
```
