# Binder M12 (Tokens) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scryfall's tokens and emblems in the playtest: imported with the card data, listed in the menu of each card
that makes them (one click makes one), searchable in Create token…, and emblems kept in the command zone (spec §5.9.8).

**Architecture:** The card data import (`src/server/bulk/import.ts`) stages tokens and emblems apart from `cards`,
with each card's links to the tokens it makes, and replaces migration 008's `tokens` and `card_tokens` in the same
transaction as `cards`; `CARD_DATA_VERSION` 3 makes older card data refresh at the next start. The deck snapshot
gives each game card the tokens it makes (`CardData.tokens`), so a game carries them like everything else it needs, and
`GET /api/playtest/tokens?q=` searches them all. In the game, an emblem is its own kind of card: the token action puts
it in the command zone, where it stays. The page adds a card's tokens to its menus and a search to Create token….

**Tech Stack:** Same as M1–M11: Node 24 running TypeScript directly, Hono 4.13, better-sqlite3 13, Zod 4, React 19.3,
TanStack Query 5, Tailwind 4, Vitest 5, TypeScript 7. No new dependencies.

**Spec:** `docs/specs/2026-09-26-binder-design.md`: §5.9.8 (Scryfall's tokens), §4.1 (`tokens`, `card_tokens`),
§4.2 (the import), §7, and §8 milestone 12. The owner approved them with M11 on 2026-09-30. Task 5 writes this plan's
rulings into them.

## Design (from the spec)

- **Tokens are never cards:** Scryfall's tokens and emblems go to their own table, one row per token, so search, the
  library, and decks never see them. Which cards make which tokens comes from Scryfall's `all_parts`.
- **In the playtest:** a card's menu lists the tokens it makes, with their images, each one click to make. Create
  token… gains a search over every token by name, and keeps the M11 form for anything missing. An emblem goes to the
  command zone.
- **Old card data:** until the card data has been imported with tokens, the lists are empty and the form still works;
  card data from an older Binder refreshes by itself at the next start.

**Decisions made while prototyping (flagged for review):**

1. **Roles are tokens.** Scryfall prints a Role as a `flip` card with a Role at each end ("Wicked // Cursed", in a
   token set), which the import used to put in `cards`, so they showed up in search. A card whose type line starts
   "Token" now goes to `tokens` like a token, double-faced token, or emblem layout.
2. **Emblem links:** Scryfall marks a planeswalker's emblem `combo_piece`, not `token` (485 links), like the reminder
   cards it lists (Morph, On an Adventure, The Monarch, checklists). A card's links are its `token` parts plus its
   `combo_piece` parts typed "Emblem" (which brings The Ring for Sauron). The reminder cards aren't linked, but they're
   in `tokens`, so Create token… finds The Monarch or Morph.
3. **Which printing a token keeps:** its newest paper printing not dated in the future, in English if there is one, as
   the default printing of a card is picked (a Beast and a Treasure printed for 2026-10-02 were already in the data).
4. **A link to a printing that isn't in the data is dropped** (a few: other languages, digital-only), as the spec says.
5. **The import's result keeps its shape:** a token counts as `skipped`, since it isn't one of the printings imported
   into `cards`.
6. **Scryfall's Copy stand-in is left out of a card's tokens:** a blank token, typed just "Token", that hundreds of
   cards list (Helm of the Host, Reflections of Littjara). Copy (a token copy) on the permanent makes the copy. It's
   still in the search.
7. **The tokens ride in the snapshot:** each game card's `CardData` gets `tokens?: CardData[]`, so a saved game needs
   nothing from the card data later and a token copy of a card makes its tokens too. `MODEL_VERSION` stays 1: an old
   game has no `tokens` and replays as before, and an action's card carries its kind, so no old action becomes an
   emblem.
8. **`CardKind` gains `emblem`** (a type line starting "Emblem", which catches The Ring's front too). The token action
   makes an emblem in its seat's command zone; moved back there from the battlefield it stays, anywhere else but the
   battlefield or the stack it vanishes like any token. It isn't played by a double-click; its menu is "Put an ability
   on the stack" and "Remove the emblem" (exile, where it vanishes).
9. **Where the tokens show:** the menu of a battlefield card that is face up (and not a selection), and of a spell on
   the stack, for the card's controller. Not in the hand, a graveyard, or the command zone. Each item is "Create Beast
   3/3" or "Get Elspeth, Knight-Errant Emblem", with the token's small image; menu items are now centred vertically,
   so the picture fits.
10. **The search:** a token's name holding the query, ignoring case, with `instr` (no wildcards to escape): the whole
    name first, then names that start with it, then the rest, 50 at most; a query of at most 100 characters.
11. **Create token…** is a wide dialog: the search on top (focused, 150 ms after typing), the tokens found as 150-px
    cards, one picked then How many and Create (Get for an emblem); the M11 form below, under "Or make one by hand".
12. **The command zone overlaps its cards past two**, each after the first showing 40% of its width, so the side
    block's piles fit.
13. **The log:** "Toxrill got an emblem: Elspeth, Knight-Errant Emblem" ("got 2 emblems: …").
14. **The search's query key is `playtest-tokens`,** apart from the game's `playtest`, so a reload of the game after a
    refused save doesn't refetch it.
15. **The fixture is ten real Scryfall lines** (`tests/fixtures/tokens.json`), committed with this plan rather than
    written out in it. Tests that depend on a date set their own (a copy "from" 2999), since the real printings' dates
    will pass.

/** Stages links from cards (by oracle id) to the token printings they make. */
export function insertTokenLinks(db: DB, links: ReadonlyArray<readonly [oracleId: string, tokenId: string]>): void {
  const stmt = db.prepare('INSERT INTO card_tokens_staging (oracle_id, token_id) VALUES (?, ?)')
  db.transaction(() => {
    for (const [oracleId, tokenId] of links) stmt.run(oracleId, tokenId)
  })()
}

/**
 * Replaces `tokens` and `card_tokens` with the staged ones (spec §4.2), inside the import's merge transaction: one row
 * per token from its best printing (TOKEN_PRINTING_ORDER), and each card's links by token identity. A link to a
 * printing that isn't in the data (digital-only, or another language) is dropped.
 */
export function replaceTokens(db: DB): void {
  const columns = TOKEN_COLUMNS.join(', ')
  db.exec('DELETE FROM card_tokens; DELETE FROM tokens')
  db.exec(`INSERT INTO tokens (${columns})
           SELECT ${columns} FROM (
             SELECT *, ROW_NUMBER() OVER (PARTITION BY oracle_id ORDER BY ${TOKEN_PRINTING_ORDER}) AS pick
             FROM tokens_staging
           ) WHERE pick = 1`)
  db.exec(`INSERT OR IGNORE INTO card_tokens (oracle_id, token_oracle_id)
           SELECT l.oracle_id, t.oracle_id FROM card_tokens_staging l JOIN tokens_staging t ON t.id = l.token_id`)
}

/**
 * The tokens each of these cards makes, by the card's oracle id, each card's in name order. Scryfall's Copy stand-in
 * (a blank token that hundreds of cards list) is left out: a copy is made from the permanent copied (Copy, spec §5.9.8).
 */
export function tokensMadeBy(db: DB, oracleIds: readonly string[]): Map<string, TokenRow[]> {
  const made = new Map<string, TokenRow[]>()
  if (oracleIds.length === 0) return made
  const rows = db
    .prepare(
      `SELECT ct.oracle_id AS maker, t.* FROM card_tokens ct JOIN tokens t ON t.oracle_id = ct.token_oracle_id
       WHERE ct.oracle_id IN (SELECT value FROM json_each(?)) AND NOT (t.name = 'Copy' AND t.type_line = 'Token')
       ORDER BY t.name COLLATE NOCASE, t.type_line, t.oracle_id`,
    )
    .all(JSON.stringify(oracleIds)) as Array<TokenRow & { maker: string }>
  for (const { maker, ...token } of rows) {
    const list = made.get(maker)
    if (list) list.push(token)
    else made.set(maker, [token])
  }
  return made
}

/**
 * Tokens and emblems whose name holds the query, ignoring case (spec §5.9.8): the whole name first, then names that
 * start with it, then the rest, each in name order. At most `limit`; none for a blank query.
 */
export function searchTokens(db: DB, query: string, limit = 50): TokenRow[] {
  const q = query.trim().toLowerCase()
  if (q === '') return []
  return db
    .prepare(
      `SELECT * FROM tokens WHERE instr(lower(name), @q) > 0
       ORDER BY lower(name) = @q DESC, instr(lower(name), @q) = 1 DESC, name COLLATE NOCASE, type_line, oracle_id
       LIMIT @limit`,
    )
    .all({ q, limit }) as TokenRow[]
}

// A small Chrome DevTools Protocol driver for the headless check (Chrome on port 9444).
export async function connect(width = 1440, height = 900) {
  // A new tab for each run, so errors logged by an earlier run aren't replayed into this one.
  const target = (await (await fetch('http://127.0.0.1:9444/json/new?about:blank', { method: 'PUT' })).json()) as { id: string; webSocketDebuggerUrl: string }
  const ws = new WebSocket(target.webSocketDebuggerUrl)
  await new Promise((resolve) => ws.addEventListener('open', resolve, { once: true }))
  let id = 0
  const pending = new Map<number, (msg: any) => void>()
  const errors: string[] = []
  ws.addEventListener('message', (event) => {
    const msg = JSON.parse(String(event.data))
    if (msg.id && pending.has(msg.id)) {
      pending.get(msg.id)!(msg)
      pending.delete(msg.id)
    }
    if (msg.method === 'Runtime.exceptionThrown') errors.push(msg.params.exceptionDetails.text + ' ' + (msg.params.exceptionDetails.exception?.description ?? ''))
    if (msg.method === 'Runtime.consoleAPICalled' && msg.params.type === 'error') errors.push(msg.params.args.map((a: any) => a.value ?? a.description).join(' '))
    if (msg.method === 'Log.entryAdded' && msg.params.entry.level === 'error') errors.push(`${msg.params.entry.text} ${msg.params.entry.url ?? ''}`)
  })
  const send = (method: string, params: object = {}) =>
    new Promise<any>((resolve, reject) => {
      const n = ++id
      pending.set(n, (msg) => (msg.error ? reject(new Error(`${method}: ${msg.error.message}`)) : resolve(msg.result)))
      ws.send(JSON.stringify({ id: n, method, params }))
    })
  await send('Runtime.enable')
  await send('Log.enable')
  await send('Page.enable')
  await send('Emulation.setDeviceMetricsOverride', { width, height, deviceScaleFactor: 1, mobile: false })
  async function evaluate<T = unknown>(expression: string): Promise<T> {
    const r = await send('Runtime.evaluate', { expression, awaitPromise: true, returnByValue: true })
    if (r.exceptionDetails) throw new Error(`evaluate: ${r.exceptionDetails.exception?.description ?? r.exceptionDetails.text}`)
    return r.result.value as T
  }
  async function waitFor(expression: string, timeoutMs = 10_000): Promise<number> {
    const start = performance.now()
    while (performance.now() - start < timeoutMs) {
      if (await evaluate<boolean>(`Boolean(${expression})`)) return performance.now() - start
      await new Promise((r) => setTimeout(r, 25))
    }
    throw new Error(`timed out waiting for ${expression}`)
  }
  async function go(path: string) {
    await send('Page.navigate', { url: `http://localhost:4455${path}` })
  }
  async function screenshot(file: string) {
    const { data } = await send('Page.captureScreenshot', { format: 'png', captureBeyondViewport: false })
    const fs = await import('node:fs')
    fs.writeFileSync(file, Buffer.from(data, 'base64'))
  }
  async function key(k: string, modifiers = 0, code?: string) {
    await send('Input.dispatchKeyEvent', { type: 'keyDown', key: k, text: k.length === 1 ? k : undefined, modifiers, code, windowsVirtualKeyCode: k === 'Tab' ? 9 : undefined })
    await send('Input.dispatchKeyEvent', { type: 'keyUp', key: k, modifiers, code })
  }
  const mouse = (type: string, x: number, y: number, extra: object = {}) =>
    send('Input.dispatchMouseEvent', { type, x, y, button: 'left', buttons: type === 'mouseReleased' ? 0 : 1, clickCount: 1, ...extra })
  /** Drags with the mouse from one point to another, in steps. */
  async function drag(from: [number, number], to: [number, number], modifiers = 0) {
    await send('Input.dispatchMouseEvent', { type: 'mouseMoved', x: from[0], y: from[1] })
    await mouse('mousePressed', from[0], from[1], { modifiers })
    for (let i = 1; i <= 8; i++) {
      await send('Input.dispatchMouseEvent', { type: 'mouseMoved', x: from[0] + ((to[0] - from[0]) * i) / 8, y: from[1] + ((to[1] - from[1]) * i) / 8, button: 'left', buttons: 1, modifiers })
      await new Promise((r) => setTimeout(r, 16))
    }
    await mouse('mouseReleased', to[0], to[1], { modifiers })
  }
  async function click(x: number, y: number, modifiers = 0, clickCount = 1) {
    await send('Input.dispatchMouseEvent', { type: 'mouseMoved', x, y })
    await mouse('mousePressed', x, y, { modifiers, clickCount })
    await mouse('mouseReleased', x, y, { modifiers, clickCount })
  }
  async function rightClick(x: number, y: number) {
    await send('Input.dispatchMouseEvent', { type: 'mouseMoved', x, y })
    await send('Input.dispatchMouseEvent', { type: 'mousePressed', x, y, button: 'right', buttons: 2, clickCount: 1 })
    await send('Input.dispatchMouseEvent', { type: 'mouseReleased', x, y, button: 'right', buttons: 0, clickCount: 1 })
  }
  async function hover(x: number, y: number) {
    await send('Input.dispatchMouseEvent', { type: 'mouseMoved', x, y })
  }
  /** The center of the first element matching a selector. */
  async function center(selector: string): Promise<[number, number]> {
    const r = await evaluate<{ x: number; y: number } | null>(
      `(() => { const el = document.querySelector(${JSON.stringify(selector)}); if (!el) return null; const r = el.getBoundingClientRect(); return { x: r.left + r.width / 2, y: r.top + r.height / 2 } })()`,
    )
    if (!r) throw new Error(`no element ${selector}`)
    return [r.x, r.y]
  }
  const close = () => {
    ws.close()
    void fetch(`http://127.0.0.1:9444/json/close/${target.id}`)
  }
  return { send, evaluate, waitFor, go, screenshot, key, drag, click, rightClick, hover, center, errors, close }
}

    method,
    headers: { host: 'localhost:4455', 'content-type': 'application/json' },
    body: body === undefined ? undefined : JSON.stringify(body),

  return res.status === 204 ? null : res.json()

const last = async () => (await saved()).actions.at(-1)

  await c.send('Input.dispatchKeyEvent', { type: 'keyDown', key: k, code: k, windowsVirtualKeyCode: code, text: k === 'Enter' ? '\r' : undefined })
  await c.send('Input.dispatchKeyEvent', { type: 'keyUp', key: k, code: k, windowsVirtualKeyCode: code })
}

  c.evaluate<Array<[string, boolean]>>(`[...document.querySelectorAll('[role="menuitem"]')].map((e) => [e.textContent.trim(), Boolean(e.querySelector('img'))])`)
/** Clicks the menu's first item starting with `label`, or, for `label` null, its first item with a picture (a token). */
async function choose(label: string | null) {
  const test = label === null ? `Boolean(e.querySelector('img'))` : `e.textContent.trim().startsWith(${JSON.stringify(label)})`
  const at = await c.evaluate<[number, number] | null>(
    `(() => { const el = [...document.querySelectorAll('[role="menuitem"]')].find((e) => ${test}); if (!el) return null; const r = el.getBoundingClientRect(); return [r.left + r.width / 2, r.top + r.height / 2] })()`,
  )

  await pause()
