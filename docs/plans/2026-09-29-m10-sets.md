## Design (the owner approved it in chat on 2026-09-29)

- **Completion:** a set is complete when the collection holds one copy of every card in it: every card identity
  (`oracle_id`) among the set's printings, in any of its printings in that set and any finish. A showcase copy counts
  for its card, basics count once each, and a reprint owned from another set counts for that set, not this one. The
  owner chose this over counting every printing (a "master set") and over a switch between the two.
- **Counted when asked** (option 1 of 3): no stored totals, no migration, no Scryfall set list (so no set symbols).
- **Sets page:** every set with a copy owned, whatever its type; a bar, owned / total, and the percentage rounded down
  (only a complete set shows 100%, gold with a check mark); sorts (completion, the default; release date; name; cards
  owned), a name-or-code filter, both kept in the address.
- **Set page:** All | Missing only (in the address); one row per card at its lowest collector number, in number order;
  copies owned across the card's printings in the set; a missing card dimmed; a row opens the card details; the whole
  set in one list.
- **Testing:** server counting and routes, the pages' pure logic, and a headless-Chrome check on a copy of the owner's
  library (ports 4455 and 9444, no `.env`, no card-data download), plus timings at 20k copies.

**Decisions made while prototyping (flagged for review):**

1. **No index, as the spec says no migration.** `GET /api/sets` reads the wide `cards` rows of every owned set's
   printings: 91 ms at 20k copies spread over 492 sets (random, so more sets than a real collection has). An index on
   `cards (set_code, oracle_id)` takes the totals from ~60 ms to 6 ms but needs migration 007 and its pre-upgrade backup.
   Left for the follow-ups, for if the page ever feels slow.
2. **Collector-number order is `Intl.Collator('en', { numeric: true })`,** not SQL: digit runs compare as numbers, so
   2 comes before 10, 7 before 7a, and The List's A25-99 before A25-101. A SQL `CAST` put letter-prefixed numbers first,
   in text order. Each card's row is its first printing in this order.
3. **Percentages round down**, so Duskmourn's 85 / 276 is 30% (the chat mock-up said 31%).
4. **Sets queries refetch with the collection and the card data.** Their key is `['sets']` (a set is
   `['sets', code]`). `invalidateCollection` refetches it after any change to copies (the card details, CSV import,
   scans). A finished card-data refresh does too: its list of queries is now `CARD_DATA_QUERIES`, exported so a test
   pins it.
5. **← Sets returns to the list as it was:** the list's link passes its address in the history state, and the All |
   Missing only switch keeps that state. A set page opened directly goes back to `/sets`.
6. **The sort and filter replace the history entry,** so Back leaves the page rather than stepping back through each
   letter typed.
7. **A set with cards owned but under 1% keeps a 3 px sliver of bar,** beside its "<1%".
8. **The set page is a table,** like Search's list view: #, Card (with its mana cost), Rarity, Copies ("✓ 2" or
   "missing"). A row opens the card details on that printing, whose Add a copy starts at it. Missing rows are at 45%
   opacity.
9. **The list's subtitle is "86 sets with cards you own".** The empty state's "import a CSV" opens the Library with its
   import panel, as Look up's Getting started does.
10. **The whole set is one list,** without virtualization: The List's 5,258 rows show 0.4 s after navigating.
11. **The end-to-end check lives in `$TMPDIR`,** as in M8 and M9, since it needs a copy of the owner's library.

- [ ] **Step 4: The counting**

`listOwnedSets` starts from the collection (as the library's queries do; `CROSS JOIN` pins that join order) and reads
only the owned sets' printings. `getSetDetail` orders a set's printings in JavaScript, where `Intl.Collator` compares
digit runs as numbers.

Create `src/server/sets/repo.ts`:

```ts
import type { SetCard, SetDetail, SetProgress } from '../../shared/types.ts'
import type { DB } from '../db/index.ts'

/**
 * Collector-number order: digit runs compare as numbers, so 2 comes before 10 (which text order reverses), 7 before 7a,
 * and The List's A25-99 before A25-101.
 */
const byNumber = new Intl.Collator('en', { numeric: true }).compare

/**
 * The sets with a copy owned, newest first, with how many of each set's cards are owned from it (spec §5.8). A card
 * counts once whichever of its printings in the set is owned, in any finish; a reprint owned from another set counts
 * for that set.
 */
export function listOwnedSets(db: DB): SetProgress[] {
  return db
    .prepare(
      `WITH owned AS (
         SELECT c.set_code, COUNT(DISTINCT c.oracle_id) AS owned
         FROM collection co CROSS JOIN cards c ON c.id = co.card_id
         GROUP BY c.set_code
       )
       SELECT o.set_code AS code, MAX(c.set_name) AS name, MAX(c.set_type) AS setType, MIN(c.released_at) AS releasedAt,
         o.owned AS owned, COUNT(DISTINCT c.oracle_id) AS total
       FROM owned o CROSS JOIN cards c ON c.set_code = o.set_code
       GROUP BY o.set_code
       ORDER BY releasedAt DESC, code`,
    )
    .all() as SetProgress[]
}

/**
 * A set and each of its cards once, at the card's lowest collector number in the set, in number order, with the copies
 * owned of the card's printings in the set (spec §5.8). The code matches in any case. Null when no printing has it.
 */
export function getSetDetail(db: DB, code: string): SetDetail | null {
  const setCode = code.toLowerCase()
  const set = db
    .prepare(
      `SELECT set_code AS code, MAX(set_name) AS name, MAX(set_type) AS setType, MIN(released_at) AS releasedAt
       FROM cards WHERE set_code = ? GROUP BY set_code`,
    )
    .get(setCode) as Omit<SetProgress, 'owned' | 'total'> | undefined
  if (!set) return null
  const printings = db
    .prepare(
      `SELECT c.id AS cardId, c.oracle_id AS oracleId, c.name AS name, c.collector_number AS collectorNumber,
         c.mana_cost AS manaCost, c.rarity AS rarity,
         COALESCE((SELECT SUM(co.quantity) FROM collection co WHERE co.card_id = c.id), 0) AS copies
       FROM cards c WHERE c.set_code = ?`,
    )
    .all(setCode) as SetCard[]
  printings.sort((a, b) => byNumber(a.collectorNumber, b.collectorNumber) || a.cardId.localeCompare(b.cardId))
  // Each card keeps its first printing in number order, and adds up the copies of all of them.
  const cards = new Map<string, SetCard>()
  for (const printing of printings) {
    const card = cards.get(printing.oracleId)
    if (card) card.copies += printing.copies
    else cards.set(printing.oracleId, printing)
  }
  const list = [...cards.values()]
  return { ...set, owned: list.filter((card) => card.copies > 0).length, total: list.length, cards: list }
```

```ts
export const SET_SORTS = [
  { value: 'completion', label: 'Completion' },
  { value: 'released', label: 'Release date' },
  { value: 'name', label: 'Name' },
  { value: 'owned', label: 'Cards owned' },

export type SetSort = (typeof SET_SORTS)[number]['value']

/** The sort named in the address, or completion when it names none. */
export function readSetSort(value: string | null): SetSort {
  return SET_SORTS.find((s) => s.value === value)?.value ?? 'completion'
}

/**
 * How much of a set is owned, in whole percent, rounded down: only a complete set is 100 (275 / 276 is 99). The
 * division is of whole numbers, so a whole result is exact (unlike 29 / 100 × 100, which is 28.999999999999996).
 */
export function setPercent(owned: number, total: number): number {
  return total === 0 ? 0 : Math.floor((owned * 100) / total)
}

/** The percentage as shown: "<1%" for a set with cards owned but under 1% (1 / 1,746), so it doesn't read as none. */
export function percentLabel(owned: number, total: number): string {
  const percent = setPercent(owned, total)
  return percent === 0 && owned > 0 ? '<1%' : `${percent}%`
}

export const isComplete = (set: Pick<SetProgress, 'owned' | 'total'>) => set.total > 0 && set.owned === set.total

/** Newer set first (the tie-break of every sort), then by name and code, so the order never depends on the input's. */
function newerFirst(a: SetProgress, b: SetProgress): number {
  return b.releasedAt.localeCompare(a.releasedAt) || a.name.localeCompare(b.name) || a.code.localeCompare(b.code)
}

const ORDER: Record<SetSort, (a: SetProgress, b: SetProgress) => number> = {
  // By the exact fraction, compared crosswise: 275 / 276 ranks above 270 / 276 though both show 99%.
  completion: (a, b) => b.owned * a.total - a.owned * b.total,
  released: () => 0,
  name: (a, b) => a.name.localeCompare(b.name),
  owned: (a, b) => b.owned - a.owned,
}

/** The sets in a new list, in the sort's order; ties go to the newer set. */
export function sortSets(sets: readonly SetProgress[], sort: SetSort): SetProgress[] {
  return [...sets].sort((a, b) => ORDER[sort](a, b) || newerFirst(a, b))
}

/** The sets whose name or code contains the text, in any case; all of them for none. */
export function filterSets(sets: readonly SetProgress[], text: string): SetProgress[] {
  const wanted = text.trim().toLowerCase()
  if (wanted === '') return [...sets]
  return sets.filter((s) => s.name.toLowerCase().includes(wanted) || s.code.toLowerCase().includes(wanted))
}

/** Scryfall's set type in words: `draft_innovation` is "Draft innovation". */
export function setTypeLabel(type: string): string {
  const words = type.replaceAll('_', ' ')
  return words.charAt(0).toUpperCase() + words.slice(1)
}

const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']

/** "Sep 2024" for 2024-09-27, read from the text itself (a Date would move it a day in time zones west of UTC). */
export function releaseMonth(date: string): string {
  const match = /^(\d{4})-(\d{2})-\d{2}$/.exec(date)
  const month = match ? MONTHS[Number(match[2]) - 1] : undefined
  return match && month ? `${month} ${match[1]}` : date
}

export function useSets() {
  return useQuery({ queryKey: ['sets'], queryFn: ({ signal }) => apiGet<SetProgress[]>('/api/sets', signal) })
}

/** One set with its cards. */
```

```ts
// A small Chrome DevTools Protocol driver for the headless check (Chrome on port 9444).
export async function connect() {
  const targets = (await (await fetch('http://127.0.0.1:9444/json/list')).json()) as Array<{ type: string; webSocketDebuggerUrl: string }>
  const ws = new WebSocket(targets.find((t) => t.type === 'page')!.webSocketDebuggerUrl)
  await new Promise((resolve) => ws.addEventListener('open', resolve, { once: true }))
  let id = 0
  const pending = new Map<number, (msg: any) => void>()
  const errors: string[] = []
  ws.addEventListener('message', (event) => {
    const msg = JSON.parse(String(event.data))
    if (msg.id && pending.has(msg.id)) { pending.get(msg.id)!(msg); pending.delete(msg.id) }
    if (msg.method === 'Runtime.exceptionThrown') errors.push(msg.params.exceptionDetails.text + ' ' + (msg.params.exceptionDetails.exception?.description ?? ''))
    if (msg.method === 'Runtime.consoleAPICalled' && msg.params.type === 'error') errors.push(msg.params.args.map((a: any) => a.value ?? a.description).join(' '))
    if (msg.method === 'Log.entryAdded' && msg.params.entry.level === 'error') errors.push(`${msg.params.entry.text} ${msg.params.entry.url ?? ''}`)
  })
  const send = (method: string, params: object = {}) =>
    new Promise<any>((resolve, reject) => {
      const n = ++id
      pending.set(n, (msg) => (msg.error ? reject(new Error(`${method}: ${msg.error.message}`)) : resolve(msg.result)))
      ws.send(JSON.stringify({ id: n, method, params }))
    })
  await send('Runtime.enable')
  await send('Log.enable')
  await send('Page.enable')
  await send('Emulation.setDeviceMetricsOverride', { width: 1400, height: 1000, deviceScaleFactor: 1, mobile: false })
  async function evaluate<T = unknown>(expression: string): Promise<T> {
    const r = await send('Runtime.evaluate', { expression, awaitPromise: true, returnByValue: true })
    if (r.exceptionDetails) throw new Error(`evaluate: ${r.exceptionDetails.exception?.description ?? r.exceptionDetails.text}`)
    return r.result.value as T
  }
  async function waitFor(expression: string, timeoutMs = 10_000): Promise<number> {
    const start = performance.now()
    while (performance.now() - start < timeoutMs) {
      if (await evaluate<boolean>(`Boolean(${expression})`)) return performance.now() - start
      await new Promise((r) => setTimeout(r, 25))
    }
    throw new Error(`timed out waiting for ${expression}`)
  }
  async function go(path: string) {
    await send('Page.navigate', { url: `http://localhost:4455${path}` })
  }
  async function screenshot(file: string) {
    const { data } = await send('Page.captureScreenshot', { format: 'png', captureBeyondViewport: false })
    const fs = await import('node:fs')
    fs.writeFileSync(file, Buffer.from(data, 'base64'))
  }
  async function key(k: string) {
    await send('Input.dispatchKeyEvent', { type: 'keyDown', key: k, text: k })
    await send('Input.dispatchKeyEvent', { type: 'keyUp', key: k })
  }
  return { send, evaluate, waitFor, go, screenshot, key, errors, close: () => ws.close() }
}
```

Create `$TMPDIR/binder-m10-check/timing.ts` (the routes at 20,000 copies):

```ts
// Times the Sets routes on a copy of the library (LIB/binder.db) grown to 20,000 copies of random English printings.
import fs from 'node:fs'
const root = process.env.ROOT as string
const lib = process.env.LIB as string
const { openDb } = await import(`${root}/src/server/db/index.ts`)
const { listOwnedSets, getSetDetail } = await import(`${root}/src/server/sets/repo.ts`)
fs.copyFileSync(`${lib}/binder.db`, `${lib}/timing.db`)
const db = openDb(`${lib}/timing.db`)
const quantities = db.prepare('SELECT quantity FROM collection').pluck().all() as number[]
const pool = db.prepare("SELECT id, finishes FROM cards WHERE lang = 'en' AND id NOT IN (SELECT card_id FROM collection)").all() as Array<{ id: string; finishes: string }>
let copies = db.prepare('SELECT COALESCE(SUM(quantity), 0) FROM collection').pluck().get() as number
const add = db.prepare("INSERT OR IGNORE INTO collection (card_id, finish, quantity, added_at, updated_at) VALUES (?, ?, ?, 't', 't')")
db.transaction(() => {
  while (copies < 20_000) {
    const card = pool[Math.floor(Math.random() * pool.length)]
    const quantity = Math.min(quantities[Math.floor(Math.random() * quantities.length)] ?? 1, 20_000 - copies)
    if (add.run(card.id, (JSON.parse(card.finishes) as string[])[0], quantity).changes === 1) copies += quantity
  }
})()
console.log(`${copies} copies in ${listOwnedSets(db).length} sets`)
function time(label: string, fn: () => unknown) {
  fn()
  const ms: number[] = []
  for (let i = 0; i < 7; i++) {
    const start = performance.now()
    fn()
    ms.push(performance.now() - start)
  }
  console.log(`${label}: median ${ms.sort((a, b) => a - b)[3].toFixed(0)} ms`)
}
time('GET /api/sets', () => listOwnedSets(db))
time('GET /api/sets/dsk', () => getSetDetail(db, 'dsk'))
time('GET /api/sets/plst', () => getSetDetail(db, 'plst'))
db.close()
```
